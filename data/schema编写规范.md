# 字段契约（schema）编写规范

正式 JSON 是规则与内容的唯一主体，字段契约（下称 schema）是这套数据的"类型系统"：它声明**某类定义允许有哪些字段、每个字段是什么类型、哪些必填、取值范围是什么**。数据作者照 schema 写内容，服务启动时按 schema 校验。

通用字段契约校验由数据核心统一实现，各领域服务在它之上注册领域类型与专用校验。

## 一、schema 放在哪里

schema 与它约束的数据**分开存放**，这是此前最容易混淆的地方：`data/战斗/定义/原子能力.json` 曾同时装结构与数据，体量大到难以阅读。

```text
data/<大类>/<组件>/定义/<类别>.json    schema：这类定义允许什么形状
data/<大类>/<组件>/内容/<类别>/*.json  数据：符合该形状的正式实体
```

约定：

- 一个 schema 文件用 `<定义名> -> {字段: {...}}` 的结构描述一类对象；
- 数据实体只写自己的取值，**不重复声明类型**；
- schema 自身也是正式 JSON，必须登记进所属组件的 `组件.json`。

## 二、字段类型

内置类型（引擎直接支持，任何领域都可用）：

| 类型 | 含义 | 可用约束 |
| --- | --- | --- |
| `字符串` | 非空文本（`允许空: true` 可放宽） | `选项`、`允许空` |
| `数字` | 整数或小数 | `最小`、`最大`、`选项` |
| `整数` | 整数（布尔不算） | `最小`、`最大`、`选项` |
| `布尔` | 真值 | — |
| `字符串数组` | 非空字符串列表 | `最少项`、`最多项`、`唯一` |
| `对象` | 嵌套对象，用 `字段` 声明子字段 | `字段`、`最少项`、`最多项` |
| `任意` | 不做检查 | — |
| `任意数组` | 必须是数组，元素不限 | `最少项`、`最多项` |

领域可以注册自己的类型。战斗领域另有自己注册的扩展类型，例如 `能力`、`能力数组`、`属性引用`、`属性数值表`、`属性构成`。

## 三、字段规格的键

| 键 | 作用 |
| --- | --- |
| `类型` | 必填，取值见上表 |
| `必填` | `true` 时数据缺该字段即报错 |
| `默认` | 缺省值；**有默认值即视为不必填**，且默认值本身也会被校验 |
| `选项` | 取值必须是列出的之一 |
| `最小` / `最大` | 数值边界，也可用于数组项数以外的数量约束 |
| `最少项` / `最多项` | 数组长度边界 |
| `唯一` | 数组元素不得重复，默认 `true` |
| `允许空` | 字符串允许为空串 |
| `字段` | 仅 `对象` 类型可声明子字段 |

写错的键会被拒绝：引擎会报「规则不认识字段 xxx」并给出完整路径。

## 四、定义对象

一个定义的顶层形状：

```json
{
  "说明": "可选，人类可读说明",
  "字段": { "字段名": { "类型": "字符串", "必填": true } },
  "约束": [
    { "当": { "字段": "某字段", "存在": true },
      "必填": ["另一个字段"] }
  ]
}
```

- `约束` 表达**条件必填**：当某字段存在或取值命中时，另一些字段必须填写；
- 领域可以扩展顶层键（战斗额外有 `类别` 与 `执行器`）。

## 五、错误信息怎么读

校验失败会给出**从数据集到具体键的完整路径**，照着路径去改对应文件即可：

```text
data/战斗/定义/原子能力.json -> 原子能力.主动技能.字段.释放顺序.类型：未知字段类型 不存在的类型
```

从右往左读：`释放顺序` 这个字段的 `类型` 写了 `不存在的类型`；它属于 `主动技能` 定义；该定义来自 `原子能力`。

## 六、新增契约的流程

1. 在 `data/<大类>/<组件>/定义` 写 schema，登记进组件清单；
2. 让该领域服务接入通用字段契约校验，按需注册领域类型、引用表与专用校验；
3. 启动时执行字段契约校验，数据不合契约即**阻止启动**；
4. 用 `tools/验证契约引擎.py` 在改数据后本地验证，不必启动整个服务。

## 七、两条硬约定

- **schema 是数据不是文档**：写进去的约束必须真的被执行。没有任何代码读取的 schema 只是装饰——`tools/架构审查/检查数据驱动.py` 会报出这类无消费者数据集。
- **不要用代码默认值替 schema 补定义**：字段缺失应当在 schema 里声明 `默认` 或 `必填`，而不是在 Python 里回退。回退值会让数据缺陷静默通过。
