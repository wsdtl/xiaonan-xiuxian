# 字段契约（schema）编写规范

schema 是数据的类型系统：声明某类定义允许哪些字段、类型、必填与取值范围。服务启动时按 schema 校验，不合即拒绝启动。通用校验由数据核心统一实现，各领域服务在其上注册领域类型。

## 放在哪里

```text
data/<大类>/<组件>/定义/<类别>.json    schema
data/<大类>/<组件>/内容/<类别>/*.json  数据
```

- schema 用 `<定义名> -> {字段: {...}}` 描述一类对象；数据只写取值，不重复声明类型。
- schema 自身也是正式 JSON，必须登记进所属组件的 `组件.json`。

## 字段类型

| 类型 | 含义 | 约束 |
| --- | --- | --- |
| `字符串` | 非空文本 | `选项`、`允许空` |
| `数字` | 整数或小数 | `最小`、`最大`、`选项` |
| `整数` | 整数（布尔不算） | `最小`、`最大`、`选项` |
| `布尔` | 真值 | — |
| `字符串数组` | 非空字符串列表 | `最少项`、`最多项`、`唯一` |
| `对象` | 嵌套对象 | `字段`、`最少项`、`最多项` |
| `任意` / `任意数组` | 不检查 / 只要求是数组 | `最少项`、`最多项` |

领域可注册扩展类型，例如战斗的 `能力`、`能力数组`、`属性引用`、`属性数值表`、`属性构成`。

## 字段规格

| 键 | 作用 |
| --- | --- |
| `类型` | 必填 |
| `必填` | 缺该字段即报错 |
| `默认` | 缺省值；有默认值即视为不必填，默认值本身也校验 |
| `选项` | 取值必须是列出的之一 |
| `最小` / `最大` | 数值边界 |
| `最少项` / `最多项` | 数组长度边界 |
| `唯一` | 数组元素不得重复，默认 true |
| `允许空` | 字符串允许空串 |
| `字段` | 仅 `对象` 类型可声明子字段 |

写错的键会被拒绝，并报出完整路径。

## 定义对象

```json
{
  "说明": "可选",
  "字段": { "字段名": { "类型": "字符串", "必填": true } },
  "约束": [
    { "当": { "字段": "某字段", "存在": true }, "必填": ["另一个字段"] }
  ]
}
```

`约束` 表达条件必填；领域可扩展顶层键（战斗额外有 `类别` 与 `执行器`）。

## 错误怎么读

```text
data/战斗/定义/原子能力.json -> 原子能力.主动技能.字段.释放顺序.类型：未知字段类型 不存在的类型
```

从右往左读：字段 `释放顺序` 的类型写错了，它属于 `主动技能`，定义来自 `原子能力`。

## 新增契约

1. 在 `定义` 写 schema，登记进组件清单。
2. 让所属服务接入通用字段契约校验，按需注册领域类型与引用表。
3. 启动时执行；数据不合契约即阻止启动。
4. 改数据后跑 `tools/全量核对.py` 的数据驱动项。

## 两条硬约定

- **schema 是数据不是文档**：写进去的约束必须真被执行；没人读的 schema 会被数据驱动判据报出来。
- **不要用代码默认值替 schema 补定义**：缺字段应在 schema 里写 `默认` 或 `必填`，不要在 Python 里回退。
