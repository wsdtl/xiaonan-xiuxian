# 玩法规则关系说明

本目录保存跨地点复用的玩法流程参数。闭关属于修行，探险、采药和采矿属于外出玩法，因此统一归入“玩法”。补天、易形、夺元的地点专属参数不在本目录保存，而在对应地点主体的 `功能配置` 中。

## 同行边界

本目录不再保存独立的“同行总规则”，`世界/位置/规则/` 下也没有同行规则文件。同行分成两个互不覆盖的事实来源：

- 玩家独行、随队、随宗的状态由人物状态、队伍、宗门三个核心各自持有；位置核心只保存每个玩家自己的坐标锚点，跟随由位置核心的一条事务完成。
- 道侣是否参与战斗、采集或其他结算，由具体玩法 JSON 自己的 `同行道侣` 字段定义。

具体玩法没有 `同行道侣` 字段时，不得读取同行道侣，也不得给予隐式加成。当前使用的参与方式是有限枚举：`并肩`进入正式参战名单，`相助`只增加采集单位；道侣的位置始终来源于所属玩家，不需要在行路玩法中重复声明“随行”。

`可无`表示没有同行道侣时玩法仍可独自进行，`必须`表示缺少同行道侣时不能开始。同行身份只决定是否纳入该玩法，伤势、消耗、成长和物资归属仍由具体玩法规则定义。

## `闭关.json`

闭关最多持续30分钟，每5分钟完成一轮，最多6轮。个人由本人开始和出关；队伍由队长、宗门同行由宗主统一带领。集体成员只能查看进度，不能单独出关。提前出关按已经完整完成的轮数向下结算，满30分钟后仍须手动出关。

```text
地点.可用功能 包含“闭关”
-> 闭关.json 计算完成轮次
-> 角色/成长/修士修炼.json.经验 处理人物经验
-> 玩家虚拟全池提供感悟候选
```

每轮为每名玩家独立进行一次功法感悟判定，道侣不参与。候选来自解析全部功法实体后形成的玩家虚拟全池，按功法自身逆权重放回抽取；品级按随机奖励规则独立抽取。同编号只在道藏保存一条：首次命中为悟得，更高品级覆盖旧品并同步已装配槽位，相同或更低品级记为复悟且没有额外收益。

## `探险.json`

只登记真正被读的参数：持续时间、每场秒数、最多场数、参与用户上限、战斗行动上限、行为状态、同行道侣方式和成长结算来源。**跨场资源连续性、敌方编组抽取、掉落均分和按时解封的细则不在数据里**，判定全在探险核心与敌人核心。自动用药阈值和选药策略只取 `玩法/服丹/规则/服丹.json`，探险不重复定义。当前一次探险最多持续 30 分钟，每场代表 120 秒，最多 15 场；我方正式单位全部战败时提前结束。每名参与用户及其同行道侣构成一个我方编组；每场先按地点决定走修士还是灵兽，两者都有时各半，再从对应阶级区间随机一阶，用 `<阶级>修士` 或 `<阶级>灵兽` 池抽一个敌方编组，人数取地点数量区间，等级用同一阶级区间。中途死亡不减少后续场次。

探险只增加每名正式参战角色自己的本命武器经验，不增加人物或道侣经验。掉落只来自敌人自身的灵石、灵兽同名兽宝池和显式额外物品池，不取得当前地形的灵植或灵矿。奖励和最终血气、精神只在结束结算时写入；开始时确定的丹药消耗与完整结果必须和探险会话一同可靠保存。

## 铜雀台地点配置

铜雀台只允许选择一名正在同行且至少二级的道侣。可抽取修为等于该道侣从一级升至当前等级已经消耗的全部修士经验，再加当前等级已有经验；突破永久属性、三类构筑、本命武器和器律均不计入可转移修为。

服用守真定契丹时，修为按 `100%` 转入人物经验，道侣好感与同行关系保持；不服丹时只转入 `70%`，好感归零、关系变为离契并返回原始地点。两种结算都会把道侣重置为初境一级零经验，清除全部等级成长、突破永久属性和突破记录；实力倍率、构筑、本命武器、自动用药设置与待战战丹保留。本命武器拥有独立等级和经验，不属于人物等级成长。

人物只能接收到当前突破上限以内的经验，溢出部分直接丢弃。玩法服务必须在扣丹和写库前返回完整预览；正式结算由后续持久化事务一次完成，不能先改道侣再尝试增加人物经验。

## 当前状态

闭关、探险、铜雀台、同行、队伍、行路和宗门园区规则都能被统一 JSON 读取服务读取。队长、宗主可以带领有序玩家同行，道侣由所属玩家按玩法规则进入正式角色名单；闭关按整轮提前出关，探险在结果全部解封后结算。宗门园区不再切换独立洞天，园区里的内层去处按本宗成员与园区坐标开放；附近查询不再按宗门洞天隔离。宗门公共资产、藏经阁、炼制设施、资源生产、贡献等级和宗门战均已形成闭环。探险、闭关和宗门战的时间与阶段统一投影为公共生命周期，重启后只从 SQLite 恢复，不重新生成结果。后续玩法仍必须从统一 JSON 读取服务取得自己的规则，不得直接读取文件、保存代码默认值或用实现反向补齐主体规则。

## 修改检查

- 时间与轮次必须能形成明确结算边界。
- 修改行动上限时评估战斗终局和战报体积。
- 所有提供探险的地点都必须给出修士/灵兽阶级区间与对应的数量区间；数量区间为正整数且下限不大于上限。
- 敌人候选少于最大遭遇人数时，只有在无重复候选已经耗尽后才能重复抽取。
- 探险掉落来自世界敌人内容，不在本目录重复配置。
- 灵植和灵矿属于采集玩法，不进入普通探险掉落。

## `采药.json` 与 `采矿.json`

采药、采矿分别拥有独立规则和行为状态，共用采集核心的六轮活动契约。两者最多持续30分钟，每5分钟完成一轮，可以提前结束并按完整轮次向下结算。玩家每轮提供一个采集单位；仍有血气的同行道侣以“相助”方式增加一个单位，所得归所属玩家纳戒。

资源池由世界核心根据开始时 `xy` 所在地形返回。采药只抽取对应灵植池，采矿只抽取对应灵矿池；结果开始时预计算，进度只展示已完成轮次，结束时分别写入参与用户纳戒。队伍由队长、宗门同行由宗主统一开始和结束，其他成员只能查看进度。

- 具体玩法只有声明 `同行道侣` 后才能取得当前同行实例；炼丹、炼器、突破等未声明玩法不得读取道侣。
- 一个玩法包含多个环节时必须逐环节声明同行方式，不能用一个总开关覆盖战斗、采掘和炼制。
- 玩法状态属于数据库实例，不能写入规则 JSON。
