# 人物培养数据包

## 功能

### 一、职责

1. **只做解析与渲染**：把玩家输入解析成玩法调用，再把结果渲染成消息；不读 JSON、不碰数据库、不做资格判断。
2. **业务在微服务**：这一目录只保存本组件的展示数据与边界说明，规则判断一律交给对应玩法微服务。

### 二、依赖

3. **依赖微服务**：业务实现住 同名或对应的玩法微服务，说明见那边的说明.md。
4. **依赖命令基础设施**：命令注册与守卫住 命令基础设施。

### 三、边界

5. **不重算规则**：数值、资格、额度都以微服务与数据包为准，命令层只转述。
6. **文案来自展示**：玩家可见的长句来自展示数据，不写死在代码里。

## 组件说明

### 命令清单

1. **「人物装配」**：把功法或一份真意、气机装入人物槽位；守卫「自主空闲或休息」。
   - 写法：「人物装配 功法 黄品五岳镇界镇岳诀 1」、「人物装配 类别 <品级><物品> 孔位」
2. **「人物突破」**：消耗对应突破丹为人物突破境界；守卫「自主空闲或休息」。
   - 写法：「人物突破 小还丹」、「人物突破 丹药编号或名称」
3. **「人物覆炼」**：把器藏中的器律覆入人物本命武器；守卫「自主空闲或休息」。
   - 写法：「人物覆炼 太白惊鸿 1」、「人物覆炼 器律编号或名称 孔位」

### 可用条件

4. **守卫**：「自主空闲或休息」。

### 边界

5. **只解析与渲染**：不读 JSON、不碰数据库、不做资格判断。
6. **业务在玩法**：数值与额度以玩法微服务为准。
