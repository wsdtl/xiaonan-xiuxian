# 灵脉组件

灵脉是宗门园区的资源产出地点：按轮次产出灵石与灵矿，产出进宗门灵藏；可选定一处地形，只抽该地形的灵矿池。

## 功能

### 一、命令

1. **「灵脉」**：查看本宗灵脉的轮次、待结算与产出；守卫「空闲或活动中」。
   - 写法：「灵脉」
2. **「灵脉 开启 / 收取 / 选地形 / 清地形」**：开启第一轮、收取成熟产出或切换矿脉；开启、收取与选地形限宗主或长老。
   - 写法：「灵脉 开启」、「灵脉 收取」、「灵脉 选地形 地形名」、「灵脉 清地形」

### 二、边界

3. **只解析与渲染**：轮次、倍率、产出与事务在对应玩法服务；命令层不自己判。
4. **规则归属**：本脉产出规则住在 `规则/灵脉.json`；产出周期与通用文案住在 共用规则包。
