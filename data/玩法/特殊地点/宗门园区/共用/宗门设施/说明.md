# 宗门设施规则包

宗门设施规则包不是地点，不挂命令、不挂页面、不出现在园区面板；它只被宗门设施玩法读取，供百炼堂、丹鼎阁、演阵台共用。

## 功能

### 一、职责

1. **身份权限**：宗主/长老/弟子的个人材料、宗门材料、圣品与发放权限。
2. **灵石消耗**：三座建筑的炼制基础消耗与品级/器阶倍率。
3. **结算约束**：失败不扣灵石、不扣材料、不产出；个人材料与宗门材料禁止混用。
4. **通用文案**：三处共用的字段名与错误标题；各处自己的场景文案住各自地点组件。
5. **不拥有建筑定义**：百炼堂、丹鼎阁、演阵台的名称、范围与支持品级各住自己的 `规则/<地点>.json`。

### 二、边界

6. **不拥有命令**：命令根在百炼堂、丹鼎阁、演阵台自己的组件里。
7. **不拥有地点**：地点身份与展示分别在三个地点组件；本包不进入园区可用功能。

## 数据集

| 数据集 | 本包路径 |
| --- | --- |
| 身份权限 | `规则/身份权限.json` |
| 灵石消耗 | `规则/灵石消耗.json` |
| 结算 | `规则/结算.json` |
| 通用文案 | `展示/通用.json` |
