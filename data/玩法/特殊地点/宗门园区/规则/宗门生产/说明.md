# 宗门生产规则包

宗门生产规则包不是地点，不挂命令、不挂页面、不出现在园区面板；它只被宗门生产玩法读取，供灵脉、灵田共用。

## 功能

### 一、职责

1. **生产周期**：轮次时长、结算口径与开启条件。
2. **设施定义**：灵脉/灵田的设施参数、地形池与产出来源。
3. **产出规则**：灵石、灵矿、灵植的产出与倍率。
4. **通用文案**：两处共用的周期、待结算、地形与错误文案；各处自己的展示住各自地点组件。

### 二、边界

5. **不拥有命令**：命令根在灵脉、灵田自己的组件里。
6. **不拥有地点**：地点身份与展示分别在两个地点组件；本包不进入园区可用功能。

## 数据集

| 数据集 | 本包路径 |
| --- | --- |
| 宗门生产周期 | `规则/生产.json` |
| 宗门生产设施 | `规则/设施/*.json` |
| 宗门生产产出 | `规则/产出/*.json` |
| 通用文案 | `展示/通用.json` |
