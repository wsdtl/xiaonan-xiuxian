# 藏经阁组件

藏经阁是宗门园区里的子地点：裸命令是地点说明页，借阅是它的分支；同类写法适用于万珍殿、灵藏、宗门。

## 功能

### 一、命令

1. **「藏经阁」**：地点说明 + 本宗共享功法第一页 + 分支提示；写法「藏经阁」「藏经阁 2」。
2. **「藏经阁 借阅 功法 [槽位]」**：从本宗道藏取最高品级，借入人物指定功法槽；不带槽位时先出槽位选择页，再回填「藏经阁 借阅 功法 槽位」。
3. **守卫**：裸命令与翻页走「已创建」；借阅分支在玩法层按「自主空闲或休息」再校验。借阅不转移个人道藏所有权，离宗时恢复原功法。

## 数据集

| 数据集 | 本包路径 |
| --- | --- |
| 藏经阁页面文案 | `展示/文本.json` |
| 藏经阁页面按钮 | `展示/按钮.json` |
| 藏经阁借阅规则 | `规则/藏经阁.json` |

## 边界

- 只做命令解析、地点说明与回复渲染；资格、槽位与借阅事务都在对应玩法服务。
- 不拥有地点、按钮表或角色槽位；这些由世界地点、世界按钮表与角色规则提供。
- 借阅按钮必须带「藏经阁」前缀，不能退回「借阅功法」这类平级根命令。
