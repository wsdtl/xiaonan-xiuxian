# 玩法大类

> 本说明只写现行规则与边界；历史变更与试玩过程见 [待补内容.md](../战斗/内容/待补内容.md)。

本大类收**通用玩法组件**：它们各自只有规则与展示（多数没有实体），一个玩法一份数据包，
够不上单开一个大类，但也不属于基础、世界、角色、战斗、物品、宗门任何一条线。

| 组件 | 内容 |
| --- | --- |
| 交易 | 修行资粮的买卖与玩家赠送 |
| 先天灵宝 | 21 件先天灵宝的权柄与规则介入 |
| 切磋 | 玩家之间的比试规则 |
| 培养 | 人物与道侣的培养投入 |
| 归元 | 归元玩法的展示文本 |
| 托管 | 托管活动与阶段的声明 |
| 探险 | 普通探险的时长、场次与奖励 |
| 易形 | 易形玩法的展示文本 |
| 服丹 | 服丹入口的展示文本 |
| 补天 | 补天玩法的展示文本 |
| 讨伐 | 讨伐首领、辅助与属从三个池 |
| 赠送 | 玩家之间的赠送规则 |
| 道侣 | 道侣结交的展示 |
| 采矿 | 按地形分档的采矿规则 |
| 采药 | 按地形分档的采药规则 |
| 铜雀台 | 铜雀台的展示与分页 |
| 闭关 | 闭关轮次与收益 |
| 队伍 | 队伍的组队与邀请规则 |

本大类自己不是组件，没有 `组件.json`；每个玩法组件一份，注册路径都以 `玩法/<组件>/` 开头。

**命名**：一个组件只要「够一个玩法的体量」就单列，不再往大类里叠第二层。真要有成体系的一族
（像 `宗门` 的山门、灵藏、藏经阁），就按 `宗门` 的样子做成**一个组件里的多个数据集**，而不是
拆成一堆小组件。
