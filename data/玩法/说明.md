# 玩法大类

只装组件，自己没有面：`通用/`、`专属/`、`特殊地点/`、`后台/`。每个玩法一个组件包，规则在该包的 `规则/`，展示在 `展示/`。

## 功能

- `通用/`：不依赖地点专属能力、NPC 或玩法实例的玩法。
- `专属/`：依赖具体玩法、地点能力或交互对象的玩法。
- `特殊地点/`：只放该地点独有的功能，建筑挂在所属地点之下。
- `后台/`：开发者隐藏入口。

## 数据集

| 数据集 | 路径 |
| --- | --- |
| 各玩法规则 | `<玩法>/规则/*.json` |
| 各玩法展示 | `<玩法>/展示/*.json` |
| 跨玩法公共参数 | `data/基础/规则/玩法说明.md` |

## 边界

- 本大类不是组件，没有 `组件.json`；每个玩法组件各自登记。
- 玩法状态属于数据库实例，不写入规则 JSON。
