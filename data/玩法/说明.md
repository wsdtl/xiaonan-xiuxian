# 玩法大类

只装组件，自己没有面：`查看与工具/`、`修行/`、`关系/`、`行动/`、`战斗/`、`炼制/`、`宗门/`、`特殊地点/`、`后台入口/`。每个玩法一个组件包，规则在该包的 `规则/`，展示在 `展示/`。

## 功能

- `查看与工具/`：查看、纳戒、角色、位置、地图、装配台、网页公开、种族、帮助、快捷、兑换码。
- `修行/`：人物培养、道侣培养、先天灵宝、服丹、血脉、意境；升阶是命令-only，数据仍在 `物品/`。
- `关系/`：道侣结交、赠送、队伍。
- `行动/`：探险、闭关、采矿、采药、行路、托管、交易。
- `战斗/`：战报、切磋、布阵。
- `炼制/`：炼丹、炼器、阵法。
- `宗门/`：宗门、宗门同行、宗门战、灵藏、万珍殿、丹鼎阁、演阵台、灵田、灵脉、百炼堂、藏经阁、共用。
- `特殊地点/`：坐忘台、太素坊、妇产科医院、归元观、裂天原、铜雀台；只装“只有该地点才有”的功能包，不拥有世界地点数据。
- `后台入口/`：天道后台，开发者隐藏入口。

## 三个例外

- `修行/升阶` 只有命令，没有玩法数据包；升阶的规则与展示归 `物品/`。
- `宗门/共用` 只有规则与展示，没有命令；它不是地点，也不进园区面板。
- `查看与工具/使用` 只有命令，没有玩法数据包；第一类展示文案暂借 `修行/人物培养` 的数据集。

## 范围

访问范围只有三个值，写在命令元数据里，不由目录推断：

- `通用`：不依赖具体玩法、对象或地点功能。
- `专属`：依赖某个玩法、对象或地点功能；具体在哪执行由守卫规则判断。
- `后台`：隐藏入口，不进玩家帮助。

`特殊地点` 是域，不是访问范围；地点专属命令仍是 `专属`，由守卫规则限定到具体地点。

## 数据集

| 数据集 | 路径 |
| --- | --- |
| 各玩法规则 | `<域>/<组件>/规则/*.json` |
| 各玩法展示 | `<域>/<组件>/展示/*.json` |
| 跨玩法公共参数 | `data/基础/规则/玩法说明.md` |

## 边界

- 本大类不是组件，没有 `组件.json`；每个玩法组件各自登记。
- 玩法状态属于数据库实例，不写入规则 JSON。
- 不保留旧 `通用/专属/特殊地点/后台` 目录，也不保留旧路径兼容层。
