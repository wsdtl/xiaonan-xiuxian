# 战丹

本目录保存只作用于下一场正式战斗的战丹，共 160 枚。旧有八类保留基础与单监听药性，新增合炼、克制、同契、劫丹和天机五类复合药性。

基础战丹直接提供整场属性状态；其余战丹通过 `使用效果.监听` 携带一到三个监听事件节点正文。战丹不保存丹方或辅材，也不引用任何编号中间层。

每枚战丹必须满足：

- `使用效果.类型` 为 `寄存战丹`。
- `强度` 是这枚丹自己的登记值（1~5），炼制难度必须落在该强度允许的档内——**这条对应关系在代码里**（`game/core/alchemy/service.py`），曾经另有一份 `规则/战丹.json` 的 `强度规则` 登记它，第 83 轮按「没人读的规则删掉」删了。
- `战前状态.持续单位` 为 `整场战斗`。
- 对应一张同编号产物的战丹丹方。
- `监听[]` 的每个节点都必须是 `监听事件`，正文自带完整文本，不从名称或说明推断效果。

## 药性就是触发面

十三个药性文件按**监听时点**分工，不按效果族分工。改一枚战丹时保持它所属药性的触发面——那是身份：

| 药性 | 触发面 |
| --- | --- |
| 控制 | `添加状态失败后` · `行动跳过后` · `技能施放前` · `普通攻击前` |
| 攻伐 | `暴击后` · `格挡后` · `闪避后` · `暴击判定前` · `命中判定前` |
| 阵势 | `护盾吸收后` · `护盾破碎后` · `技能冷却变化后` · `技能冷却完成后` |
| 应变 | `暴击后` · `格挡后` · `闪避后` · `护盾破碎后` · `击杀后` |
| 资源 | `资源变化后` · `资源消耗前` · `资源消耗后` · `资源恢复后` |
| 绝境 | `受到致命伤害` · `受到伤害后` · `击杀后` · `死亡后` |
| 劫丹 | `受到致命伤害` · `技能施放失败后` · `资源消耗前` · `形态切换后` |
| 克制 | 六个「…前」（添加状态前 / 技能施放前 / 恢复前 / 暴击判定前 / 行动决策前 / 普通攻击前） |
| 天机 | `造成伤害前` · `行动结束` · `行动决策后` · `战斗开始` |
| 同契 | `行动结束` · `受到伤害后` · `战斗对象入场后/退场后` |
| 援护 | `受到伤害后` · `行动结束` · `死亡后` · `击杀后` |
| 合炼 | 不设面：它是多段联动，监听铺得最散（32 个时点） |
| 基础 | 不监听，直接给整场属性状态（与气机同理，是纯定值属性） |

所以"控制类不控制、攻伐类很少打人"不是缺陷：**药性命名的是它响应什么，不是它造成什么**。

## 四维位置要摊开

作用角度 = 时机 × 对象 × 手段 × 持续。战丹的"持续"被 `寄存战丹` + `整场战斗` 锁死，
"时机"由药性的触发面决定，能动的是**对象**与**手段**。同一格里挤着多枚时，
按药性的机制优先表给其中几枚补一件"本来该有"的机制（合炼补计量、劫丹补保命、
资源补节奏、控制补减益……），取表里第一个它还没有的；同格内轮转，不补同一件。
同契 / 援护 / 合炼 里强度 ≥ 4 的，把恢复对象从自身改到己方。

摊开前 148 枚落在 56 个签名格里、最大一格 18 枚；摊开后 88 格、最大 6 枚
（12 枚基础档仍同格，它们是纯定值属性，跟气机同理）。工具 `tools/战丹角度摊开.py`。

**护盾不是独立原子能力**：给护盾要用 `恢复资源` 且 `资源` 填 `护盾`
（`获得护盾` 这个原子不存在，写了会在真实对局里抛错）。
