# 炼药内容关系说明

本目录保存丹药实体——**它自己就是处方**（第 76 轮把丹方并了进来）。丹药放在 `物品/炼丹/内容/丹药`；108 株灵植和全部兽宝继续保留各自的来源池，不为炼药复制实体定义。灵矿暂不参与炼药。

```text
物品/炼丹/规则/丹则.json
  -> 药引类别：兽宝
  -> JSON 数据微服务按编号类别形成 366 个兽宝的虚拟全池

丹药/恢复丹/*.json、丹药/战丹/*.json、丹药/突破丹/*.json
  -> 炉法：物品/炼丹/规则/炉法.json
  -> 用哪味药、炼出来是什么：都写在这一条实体自己身上
```

丹药按用途使用稳定编号：恢复丹 `10`、战丹 `12`、突破丹 `14`、特殊丹 `16`。选定入炉后使用具体兽宝编号。战丹按方向拆分文件，突破丹按境界节点组织，特殊丹按长期成长和构筑流程拆分，最低材料品级由炼制难度规则统一推导，不在每条丹药重复保存。丹药名称可以修改，编号不可修改。

## 修改检查

- 每条丹药必须引用一门已有炉法，并写明炼制难度。
- 战丹的 `强度`、`炼制难度` 与「自己没有单独丹方」三条口径，见 [丹药/战丹/说明.md](丹药/战丹/说明.md)。
- 药引类别由 `丹则.json` 唯一定义，丹药不得重复声明药引池。
- 全部兽宝都应通过编号类别虚拟全池可达；全部灵植都应通过归脉关系参与至少一门炉法。
- 丹药不保存具体辅材清单、评分、平衡记录或业务执行状态。
