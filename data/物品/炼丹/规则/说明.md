# 炼药规则关系说明

> 本说明只写现行规则与边界；历史变更与试玩过程见 [待补内容.md](../../../战斗/内容/待补内容.md)。

炼药只遵循一条主线：兽宝为引，灵植为辅，循药脉、行炉法、依丹药成丹。丹药不逐项罗列具体灵植，避免把炼药退化成重复填表。灵矿不属于炼药辅材，也不进入归脉。

## 五层规则

```text
归脉.json：灵植池 -> 本脉 + 旁脉
炉法.json：炉法 -> 所需药脉与味数
丹则.json：本脉取材、旁脉替代与成丹
难度.json：全部丹药共用的辅材味数与最低材料品级
```

四条规则管炼制。**战丹的寄存边界不在这里**：它登记在 `玩法/服丹/规则/服丹.json` 的 `战丹`
一节（每个角色上限 1、同编号不重复、已有待战战丹时拒绝、服下即扣除、只在下一场正式战斗
生效、测试战斗不生效、正常结束清除、中止保留），由服丹服务执行；寄存边界的完整口径另见 [服丹规则](../../../玩法/服丹/规则/服丹.json) 与 [服丹说明](../../../玩法/服丹/说明.md)。**强度与炼制难度之间没有对应表，也没有匹配校验**（战丹实体的口径见
[内容/丹药/战丹/说明.md](../内容/丹药/战丹/说明.md)）。

五条药脉分别是：

| 药脉 | 丹道取向 |
| --- | --- |
| `青华` | 生发、续养、复苏 |
| `丹离` | 催化、激发、炼化 |
| `坤载` | 承载、镇固、调和 |
| `太白` | 凝练、锋锐、收束 |
| `玄冥` | 润养、潜藏、沉静 |

每个灵植池只登记一次本脉和一次旁脉。炉位所需的本脉、旁脉灵植数量取自 `丹则.json`；**同一灵植的占位上限与「一味本脉或两味旁脉占一位」的折算法在炼药服务里**，`丹则.辅材` 只留 `来源.字段` 与 `旁脉替代上限`。具体丹药允许的旁脉替代次数再受 `难度.json` 收紧：难度 1 至 8 每炉至多旁脉替代一次，难度 9 至 10 禁止旁脉替代。

炉法只保存名称和辅材结构。过去的 `炉势` 是不参与计算的自然语言描述，已经删除；炉法差异完全由药脉与味数决定。丹药只保存炉法与炼制难度，药引类别统一取自 `丹则.json`，因此同一兽宝可以随不同炉法炼成不同丹药，新增灵植也只需要补一次归脉关系。

战丹强度衡量下一场战斗收益；炼制难度衡量药性调和复杂度，决定炉法味数、最低材料品级和旁脉替代上限。两者不是同一尺度，同强度可以有不同炼制难度。**强度与允许炼制难度之间没有对应表、也没有匹配校验**，数据侧只保存每枚丹自己的 `强度` 与 `炼制难度`；战丹侧的三条修改检查见 [内容/丹药/战丹/说明.md](../内容/丹药/战丹/说明.md)。恢复丹与突破丹只使用炼制难度，不声明战丹强度。

成丹数量取 `丹则.json.成丹.基础数量`。成丹品级使用“最低余量进阶”：先取药引与辅材最低要求中较高的品级为基础，再取所有实际材料各自超过最低要求的最小阶数作为进阶余量；当前每一阶余量提升一阶成丹品级，且不超过规则登记的最高品级。城镇丹炉再受 `城镇最高品级` 限制，当前封顶天品；宗门丹鼎阁走宗门设施规则，可以炼制圣品。

## 战丹时限

战丹服下后先寄存在人物状态中，只在下一场正式战斗开始时转成 `战前状态`。正常结算后清除；测试战斗不生效，中止战斗不消耗。这两条由 `玩法/服丹/规则/服丹.json` 的 `战丹` 一节登记、服丹服务校验；战斗核心只接收已经装配好的状态，不读取丹药、纳戒或炼药业务。

## 修改检查

- 54 个地形灵植池、108 株灵植必须全部通过 `归脉.json` 进入炼药，不能遗漏或重复。
- 炉法只能引用 `青华`、`丹离`、`坤载`、`太白`、`玄冥`。
- `丹则.json` 的药引类别必须是兽宝，炉法必须存在，成丹编号必须存在。
- 战丹的 `强度`、`炼制难度` 与丹方归属三条，按 [内容/丹药/战丹/说明.md](../内容/丹药/战丹/说明.md) 核；恢复丹与突破丹只核炼制难度与炉法味数。
- 炼药业务以后只消费 `炼药规则`、`丹药`、`灵植`、`兽宝` 数据集。
