# 阵法规则关系说明

本目录只保存所有阵法共用的炼制和数值计算规则，不保存具体阵法，也不决定阵法在哪里开放。

```text
物品/阵法/内容/阵法.json
  + 物品/阵法/规则/炼制.json
  + 兽宝、灵矿、灵植的实际投入数量
  -> 阵法业务生成一次性阵法实例
  -> 战斗建立时固化本场宏观数值快照
  -> 战斗核心执行阵法轮转、阵基对撞与节点覆盖
```

`炼制.json` 规定三类材料与阵基、阵眼、节点的对应关系（`圣品增长.方向`），以及黄、玄、地、天固定投入和圣品无上限投入。城镇阵台最高支持天品，宗门演阵台按宗门身份和灵石消耗规则开放圣品。圣品使用 `算法`、`方向`、材料投入和结果字段结构化计算，不保存公式字符串。规则只读取材料类别、品级和数量，不解释某件材料的名称、药性、铸脉、掉落地点或战斗能力。

没有敌方阵法时，节点数量决定单次冲击能够覆盖的正式参战者数量，总冲击在实际覆盖目标间均分。存在敌方阵法时优先冲击敌方阵基，节点不绕过阵基直接攻击参战者。

每座阵法的身份、五品配置和三类圣品权重属于 `物品/阵法/内容/阵法.json`。阵师实体按稳定编号在所属地点目录声明当地开放的阵法；阵法实例保存阵法编号、品级和真实投入，不复制规则正文与最终计算结果。

## 当前状态

阵法规则与 46 座阵法由 JSON 微服务加载、编号校验并建立索引。阵法核心读取阵法编号、品级、方位和真实材料投入，生成本场只读阵法快照；战斗核心只执行该快照。其他服务不得自行解释阵法正文或复制圣品计算公式。
