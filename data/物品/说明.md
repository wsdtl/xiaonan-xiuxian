# 物品大类

> 本说明只写现行规则与边界；历史变更与试玩过程见 [待补内容.md](../战斗/内容/待补内容.md)。

本大类收**造物与器物**的四条线：材料、丹药、器律、阵法。它们共享同一条「按编号前缀分流」的
读法，也共享同一批品级与分类规则，所以住在一起。

| 组件 | 目录 | 内容 |
| --- | --- | --- |
| 基础物品 | `基础物品/` | 灵植、灵矿、兽宝三种来源池与物品分类、使用效果 |
| 炼丹 | `炼丹/` | 丹药实体（自带处方：炼制难度 + 炉法）、炼丹规则、炼丹师展示 |
| 炼器 | `炼器/` | 器律实体（自带器阶 / 铸法 / 兽引与完整能力树）、器则、铸法、炼器工匠展示 |
| 阵法 | `阵法/` | 阵法实体、炼制规则、阵法字段契约与阵师展示 |

**方法与实体合在一处**：丹药自己写着「怎么炼」与「炼出来是什么」，
器律自己写着「怎么铸」与「铸出来是什么」，都不再另立一份只有方法的实体。判据见
`tools/架构审查/检查炼丹形状.py`。

本大类自己不是组件，没有 `组件.json`；四个组件各自一份，注册路径都以 `物品/<组件>/` 开头。
