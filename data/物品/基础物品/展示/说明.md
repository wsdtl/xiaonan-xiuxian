# 纳戒展示

> 本说明只写现行规则与边界；历史变更见 git 历史，待补事项与缺功能见 [待补内容.md](../../../战斗/内容/待补内容.md)。

`分类.json`登记玩家资产在纳戒中的大类、小类、图标、顺序和分页上限。

```text
数据库中的玩家资产状态
+ JSON 实体编号、品级、器阶与名称
+ 物品/基础物品/展示/分类.json
-> 纳戒大类与小类
-> 每个小类不超过 50 条的稳定分页
```

数据库不复制展示分类。玩家资产核心根据状态类型、实体编号和正式 JSON 定义归类：普通物品、真意、气机和天地玄黄阵法按`编号 + 品级`合并；功法和器律按编号合并，其中功法只保留最高品级；圣品阵法的真实投入实例单独保留；丹药按编号保存。

纳戒是统一只读入口，不拥有服丹、装配、覆炼、布阵或炼制的写权限。修改分类时必须保证每个状态类型和每条资产只命中一个小类，且每页上限不得超过 50。
