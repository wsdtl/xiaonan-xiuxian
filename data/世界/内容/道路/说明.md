# 全境道路关系说明

> 本说明只写现行规则与边界；历史变更与试玩过程见 [待补内容.md](../../../战斗/内容/待补内容.md)。

本目录保存晓楠修仙界实际存在的道路。文件名就是道路类别，根节点直接使用道路字典列表，不增加同名外层键。

共118条道路，覆盖全部81个地点并形成一个连通网络。道路坐标由统一山河骨架结合地势坡度重新寻路，不穿过与端点无关的城镇。

## 单条道路

```json
{
  "起点": "溪隐台",
  "终点": "青溪津",
  "途经坐标": [[8, 8], [8, 9], [8, 10], [8, 11], [8, 12], [8, 13], [8, 14]]
}
```

起点和终点引用地点文件名。`途经坐标` 保存从起点到终点的连续 `(x, y)`，每一步只能移动到八个相邻格之一；首格和末格必须分别等于两个地点的水平坐标，道路中段不得穿过非端点地点。道路默认双向，不重复保存反向道路。

道路不保存 `z`、距离、坡度、评分、推荐境界或使用记录。运行时从 `地势.json` 取得每格高度，再按实际行进方向计算路线剖面；发生地势修改时道路无需复制高度，但必须重新校验最优路线与行程叙事。

## 引用关系

```text
晓楠修仙界.json.道路 ------------------> 本目录七个道路文件
道路.起点/终点 ------------------------> 地点文件名
道路.途经坐标 ------------------------> 地势.json 的 (x, y)
世界/行路/定义/行程指标.json --------------> 可计算的路线指标
世界/行路/规则/行程.json ------------------> 全地表坐标连续性、自动选路和路程折算
世界/行路/规则/道路通行.json --------------> 正式道路坐标边的通行倍率
世界/行路/规则/地形通行.json --------------> 非道路坐标边的通行倍率
世界/行路/展示/行程.json -------------------> 玩家看到的行程叙事
```

## 修改检查

- 新路的端点必须是已登记地点，首尾坐标必须与地点一致。
- 相邻坐标不得越界、跳格或重复，整条路不能形成自环。
- 道路中段不得命中其他正式地点；需要途经该地点时，必须拆成以它为端点的真实道路关系。
- 同一对地点当前只能存在一条直接道路；需要并行路线时必须先增加稳定道路身份规则。
- 删除道路后仍须保证需要开放的地点可从出生地到达。
- 世界服务校验道路端点、逐格连续性、重复端点和全境连通性，并提供自动选路；行路玩法负责生成路线文本并立即提交玩家位置变更，不保存等待式行程进度。
