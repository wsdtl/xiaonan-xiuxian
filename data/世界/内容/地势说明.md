# 全境地势关系说明

> 本说明只写现行规则与边界；历史变更见 git 历史，待补事项与缺功能见 [待补内容.md](../../战斗/内容/待补内容.md)。

`地势.json` 是晓楠修仙界唯一的地表高度事实表。世界只有一个界，`z` 只表示真实高度，不表示位面、次元或世界编号。

## 坐标与尺度

```text
x轴：0..99
y轴：0..99
水平分辨率：1
水平每格：10000米
海拔范围：-33333..28710米
高度分辨率：1米
海平面：0米；低于海平面的湖泽、河口和湿地使用负高度
```

全表共有100行，每行100个整数。数组第一层按 `y` 索引，第二层按 `x` 索引：

```text
H(x, y) = 地表高度[y][x]
```

`H` 返回该水平坐标的地表 `z`。完整空间点仍使用 `(x, y, z)`；`z=H(x,y)` 是地表，低于它是地下，高于它是地表上方。本文件只定义地表，不额外生成地下洞窟或空中浮岛。

## 地势组成

高度场覆盖现有11个区域走势、85片独立地形和81个地点坐标：

- 东、西、南最外缘落入海面以下，三条海岸各自按多尺度曲线形成宽窄不一的海湾、岬角和浅滩，海深随离岸距离连续衰减；沿岸地点和道路仍保留原有高度，形成港湾、陆堤、岛屿与通海道；
- 东南离岸角落下切至-33333米，形成独立的万丈天渊，不把镜湖州内陆整体拖成低地；
- 镜湖州、玄河州的湖滨、湿地、沙洲和河口维持在低海拔；
- 青岚州、丹霞州、云京州形成南方丘陵、山麓、云岭和丹崖；
- 镇岳防线横贯中部，山口、山脊与峡谷形成连续防守地势；
- 朔风荒原和寒渊林海保留草原、寒林、冰谷与寒沼的高低变化；
- 北缘从烬脊群山与天裂禁地南界开始连续抬升，将黑岩、熔火、灰烬、雷谷与断崖整理成不等高的封界群山；无光崖保留28710米峰值，周围不再形成整片封顶平台。

地势不是单一方向的线性抬升，也不是全局三次多项式。内陆继续保留原有局部起伏；环海、北缘群山与东南天渊只修改边缘地貌。地点和道路坐标仍作为精确高度锚点，最终结果固化为整数高度表，因此运行时只需查表。

## JSON 关系

```text
地势.json.坐标边界 ---------------------> 全境唯一水平边界
地势.json.水平每格米数 -----------------> 水平距离与坡度换算
地点.json.坐标[2] ---------------------> 地表高度[y][x]
道路.途经坐标 -------------------------> 逐格读取地表高度形成路线剖面
区域.json.坐标带 ------------------------> 运行时计算区域海拔最小值与最大值
地形分区.json.坐标带 --------------------> 任意坐标的唯一地形与战场环境
地势.json.海拔范围 ----------------------> 全境地表最小值与最大值
```

地点只保存 `(x, y)` 平面坐标，海拔统一从 `地势.json` 取得。区域和世界不复制海拔范围，区域摘要由世界服务按真实坐标带计算，不能用外接矩形混入邻区地势。

## 修改检查

- `地表高度` 必须保持100×100，且每项为全境 `海拔范围` `-33333..28710` 内的整数。
- 所有81个地点的二维坐标必须位于 `0..99`，地点海拔只能读取对应格高度。
- 最外缘外海和东南天渊不得覆盖正式地点或道路坐标；海岸道路保留原有路线剖面。
- 每个区域的运行时海拔范围必须由该区域坐标带内全部地表高度计算。
- 地势修改不得产生空洞、缺行、非数字或未登记的跨界层。
- 行路不能直接把水平格差与垂直米差相加；水平距离按每格10000米换算，垂直升降按 `世界/行路/规则/行程.json` 折算。
