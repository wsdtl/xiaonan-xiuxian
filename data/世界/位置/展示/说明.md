# 位置展示

> 本说明只写现行规则与边界；历史变更与试玩过程见 [待补内容.md](../../../战斗/内容/待补内容.md)。

位置展示把已经完成范围过滤的位置事实组织为`位置`和`附近`回复。

```text
玩家地表 xy
+ 世界核心推导的地点、区域、地形与海拔
+ 地点事实中的可用功能
+ 已经建立按钮映射的地点功能
+ 范围内的动态修士和当前地点的道侣
+ 规则/距离与方向.json
+ 规则/{文本,图标}.json
+ 按钮/{地点功能,位置,附近}.json
-> 当前位置、附近概览、修士分页和地点列表
```

地点 JSON 的 `可用功能` 是世界事实；`按钮/地点功能.json` 保存已经上线的地点专属功能按钮。位置和行路抵达回复的底部地点面板只展示两者的交集，正文不再重复列举同一功能。地点可以提前声明未来功能，但对应玩法命令完成前不得增加按钮映射。

`按钮/地形功能.json` 保存采药、采矿等通用地形行为。位置和行路抵达回复依据世界核心实际返回的灵植池、灵矿池决定是否显示，不把通用行为重复写入每个地点的 `可用功能`。

## 文件职责

| 文件 | 职责 |
| --- | --- |
| `规则/距离与方向.json` | 里数折算、同处措辞和八方向名称 |
| `规则/文本.json` | 回复栏目名称、空状态和组合模板 |
| `规则/图标.json` | 回复栏目使用的消息图标 |
| `按钮/地点功能.json` | 已上线地点功能对应的完整命令按钮 |
| `按钮/位置.json` | 当前位置页面的固定动作 |
| `按钮/附近.json` | 附近概览、分页、地点页和动态行路动作 |

本目录不改变`世界/位置/规则/附近.json`中的查询半径、候选上限、公开状态或分页数量。本地修士来自世界道侣定义，动态修士来自角色公开摘要，二者不能互相替代。

位置与行路抵达回复展示完整地点面板；地点专属组件在自身业务按钮之后复现同一面板；其他组件只保留自身强联动按钮。三类之外的回复不得附加按钮。

修改方向或距离单位时检查八方向完整且与行程距离尺度一致；修改文本或按钮时初始化位置玩法，检查模板占位符、页面、条件、行为、样式和动作编号。未知功能、重复按钮、未注册命令和死按钮属于维护检查，只能由 `tools` 手动审查，不得挂入游戏启动流程。
