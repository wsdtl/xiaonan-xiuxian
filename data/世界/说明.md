# 世界数据包

本包按组件维护数据，文件归属由 [组件.json](组件.json) 声明。数据集名是公共读取契约；编号、池文件名不随目录变化。

## 功能

### 一、启动期把规则读死
1. **依赖与初始化**：`initialize` 先要求 JSON 数据服务已加载（否则抛「JSON 数据服务必须先于世界地点服务启动」），再按「地势 → 区域 → 地形分区 → 地点功能 → 地点 → 世界」的顺序建索引，全部通过后置 `_initialized` 并返回 `WorldStatus`；重复调用抛「世界地点服务已经初始化」。（`game/core/world/service.py`）
2. **世界唯一**：`世界` 实体必须且只能有一份，否则报错；`出生地` 去空白后必须是已登记地点名。（`内容/晓楠修仙界.json`、`game/core/world/service.py`）
3. **地势硬校验**：`地表高度` 必须是非空二维整数数组，其行数、每行列数必须等于 `坐标边界` 推出的 y、x 尺寸，`海拔范围` 必须等于高度表的真实最小、最大值（`[-33333, 28710]`），`水平每格米数` 必须是正整数（10000）。（`内容/地势.json`、`game/core/world/service.py`）
4. **区域域**：每个区域只许有 `类别`、`坐标带`、`说明` 三个字段，`类别` 与 `说明` 必须非空；`坐标带` 按 y 分层，每层只许 `y`、`x轴`，y 不得越界或重复，x 区间必须有序、不重叠、落在边界内；域必须四向连通、完整覆盖 `x轴 [0, 99]`、`y轴 [0, 99]` 的 10000 格且互不重叠，缺格或多格都报错。（`内容/<区域>/<区域>.json`、`game/core/world/service.py`）
5. **地形域**：`地形分区` 必须是字典列表，每片只许 `名称`、`地形`、`坐标带`，名称与地形非空且名称唯一；连通性、完整覆盖、互不重叠的要求与区域相同；每片使用的地形必须存在同名 `战场环境` 实体，否则报「地形缺少同名战场环境」。（`内容/地形分区.json`、`game/core/world/service.py`）
6. **地点字段闭合**：地点主体只许出现 `坐标`、`说明`、`可用功能`、`功能配置`、`单次遭遇敌人倍率` 五个字段，多一个字段即报「存在未声明字段」；`坐标` 必须是两个整数，`说明` 必须非空。（`内容/<区域>/<地点>/<地点>.json`、`game/core/world/service.py`）
7. **坐标与区域对齐**：地点坐标不得重复，目录所属区域必须等于 `_region_at(xy)` 查出的区域，地形必须落在某片分区内，两处不一致都在启动期报错。（`game/core/world/service.py`）
8. **派生池就绪**：每个地点按其地形要求 `灵植-<地形>` 与 `灵矿-<地形>` 两个池都已在 `基础物品` 中登记，缺池即报「派生资源池无效」。（`内容/地形分区.json`、`game/core/world/service.py`）

### 二、地点功能与同目录内容
9. **功能定义校验**：`地点功能` 必须是字典列表，每项只许 `名称`、`同目录内容`、`要求`、`地点配置`，名称非空且不重复，`地点配置` 必须是布尔值。（`定义/地点功能.json`、`game/core/world/service.py`）
10. **同目录内容白名单**：`同目录内容` 只接受「道侣 / 敌人 / 商店 / 炼器工匠 / 炼丹师 / 阵师 / 讨伐 / 讨伐首领 / 讨伐辅助 / 讨伐属从」，出现别的值即拒绝。（`定义/地点功能.json`、`game/core/world/service.py`）
11. **要求字段**：`要求` 只许 `非空字段`、`正数范围字段`，两者不得交叉，字段名必须属于地点五字段；`正数范围字段` 的值必须是两个顺序正整数（`单次遭遇敌人倍率` 走这条）。（`定义/地点功能.json`、`game/core/world/service.py`）
12. **按功能汇总要求**：地点声明的每个功能把 `非空字段` 与 `正数范围字段` 合并成必填集合，逐字段校验非空或正整数范围；地点里出现不属于任何声明功能的可选字段即报「字段没有对应功能要求」。（`game/core/world/service.py`）
13. **专属配置缺失检查**：`功能配置` 的键必须是 `可用功能` 的子集且值必须是对象，标记 `地点配置` true 的功能必须在该地点 `功能配置` 中恰好出现，缺失即报「缺少专属功能配置」。（`定义/地点功能.json`、`game/core/world/service.py`）
14. **实体与池落地**：`商店` 要求同目录存在 `<地点>商店` 且其 `directory_owner` 等于地点；`炼器工匠`/`炼丹师`/`阵师`/`讨伐`/`讨伐首领`/`讨伐辅助`/`讨伐属从` 要求实体来自同目录文件且不得重复保存 `地点` 字段；其余内容走 `<地点><内容>` 池并要求池成员都落在该地点目录内。（`定义/地点功能.json`、`game/core/world/service.py`）
15. **专属功能读取**：`feature_config(function)` 只按功能名取配置，先反查声明该功能的地点，数量不为 1 即报「地点专属功能必须且只能有一个地点」，再要求 `功能配置.<功能名>` 是对象。（`game/core/world/service.py`）
16. **实体字段契约**：`定义/字段契约.json` 为「道侣 / 炼器工匠 / 炼丹师 / 阵师」四类声明 `必填字段`，世界道侣、炼器工匠、炼丹师、阵师各自的领域核心在启动时按该契约校验实体。（`定义/字段契约.json`、`game/core/world/__init__.py`）

### 三、地点查询与派生视图
17. **查询入口**：`locate(LocationQuery)` 要求地点名与 xy 恰好给一个，两个都给或都不给都抛「地点查询必须只提供地点名或 xy」；按名查要求地点已登记，按 xy 查先做边界校验（越界抛「xy 超出世界边界」）。（`game/core/world/service.py`）
18. **野外回退**：按 xy 未命中登记地点时地点名与 `location_key` 为空串，区域改由 `_region_at` 给出，仍照常返回地形、海拔与 `environment_id`。（`game/core/world/service.py`）
19. **派生池字段**：`LocationView` 固定带 `plant_pool`=`灵植-<地形>`、`mineral_pool`=`灵矿-<地形>`；`companion_pool` 只在内容集合含「道侣」且地点非空时给 `<地点>道侣`，`enemy_pool` 同理给 `<地点>敌人`；`enemy_multiplier` 读地点的 `单次遭遇敌人倍率`，非数组时返回空元组。（`game/core/world/service.py`）
20. **行路编排入口**：`plan_journey(JourneyQuery)` 先确认规划器已构建，把 `origin_xy` 与目的地各过一次 `locate`，再交给 `JourneyPlanner.plan`；未初始化时抛「世界地点服务尚未初始化」。（`game/core/world/service.py`、`game/core/world/journey.py`）

### 四、地图快照
21. **快照协议**：`map_view()` 返回初始化时一次构建的 `WorldMapView`，`schema` 为 `game.world_map.presentation`、`version` 为 2，内含世界名称与说明、出生地、坐标边界、每格米数、海拔范围、100×100 地表高度场、区域、地形分区、地点与道路。（`game/core/world/contracts.py`、`game/core/world/service.py`）
22. **每块坐标域派生**：区域与地形分区都附带外接边界、标签坐标（最接近格重心的格子，同距按 y、x 取小）、格数与坐标带；区域另带与之相交的地形分区名列表；坐标带把同 y 的 x 合并成连续区间。（`game/core/world/service.py`）
23. **排序与消费方**：区域按 (y 下界, x 下界, 名称) 排序，地形分区按名称排序，地点按 (y, x, 名称) 排序；公开地图玩法、位置玩法的附近地点、交易与锻造/炼丹/炼阵的地点对齐都只读这份快照。（`game/features/ditu/service.py`、`game/features/weizhi/service.py`、`game/core/trade/service.py`、`game/core/world/service.py`）

### 五、道路
24. **世界道路声明**：世界 `道路` 必须至少引用一种类别，引用的每个类别都必须在 `道路` 数据集中存在，否则报「世界引用不存在的道路」；每个道路文件必须是字典列表。（`内容/晓楠修仙界.json`、`内容/道路/*.json`、`game/core/world/service.py`）
25. **逐条道路校验**：`起点`、`终点` 必须是已登记地点，`途经坐标` 必须非空、逐点落在世界边界内、相邻点不得原地也不得跨格，首点坐标必须等于起点地点坐标、末点坐标必须等于终点地点坐标，中段不得命中任何非端点地点。（`内容/道路/*.json`、`game/core/world/service.py`）
26. **边类型唯一**：行路规划器把每条道路逐段展开成无向边，同一坐标边若同时属于两种道路类型即抛「同一坐标边存在不同道路类型」，世界初始化随之失败；世界自身的 `行程规则` 字段不被世界核心读取，行路参数一律来自行路数据集。（`内容/道路/*.json`、`game/core/world/journey.py`）
