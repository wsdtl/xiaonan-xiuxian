# 行路规则关系说明

> 本说明只写现行规则与边界；历史变更见 git 历史，待补事项与缺功能见 [待补内容.md](../../../战斗/内容/待补内容.md)。

本目录只负责从全境路网自动选出最合适的行程并生成结构化行程事实，不保存具体道路、玩家状态或展示文本。

## `行程.json`

```text
任意起点 xy 与任意终点 xy
-> 在 100 × 100 地表上展开八方向相邻步
-> 道路坐标边使用道路通行倍率
-> 其他坐标边使用两端地形倍率平均值
-> 按逐格坐标读取地势高度
-> 计算距离、升降、道路段数和折算路程
-> 依次比较折算路程、道路段数、水平距离
-> 取得唯一最优行程
-> 交给世界/行路/展示/行程.json 生成行程叙事
```

玩家只选择目的地，不选择道路。登记地点、野外坐标和未来的宗门坐标都使用同一套全地表寻路。没有正式道路不再视为数据错误，只代表整段行程都在地形上行走。

## `道路通行.json`

每种正式道路登记一个通行倍率。道路只覆盖对应坐标边的地形倍率，不覆盖海拔带来的上升和下降成本。同一坐标边只能归属一种道路类型；同类型道路可以复用已有道路边，异类道路重叠会在世界核心初始化时被拒绝。

## `地形通行.json`

每种地形登记一个通行倍率，必须完整覆盖 `世界/内容/地形分区.json` 使用的地形且不能重复。非道路坐标边使用起点和终点地形倍率的平均值，避免地形边界产生单格穿越漏洞。

## 境界边界

二十个境界各自拥有独立赶路方式和三段展示措辞，但不改变目的地可达性、道路选择和折算路程。行路立即抵达，不计算境界速度。剧情封锁、阵法阻断或战争封锁需要未来独立内容明确声明，不能借海拔或境界自动产生。

## 修改检查

- `道路通行.json` 必须与地图登记的道路类型一一对应。
- `地形通行.json` 必须与全境地形分区使用的地形名称一一对应。
- 自动选路始终由规则完成，聊天指令不暴露逐段道路选择。
- 地势、道路、地形倍率或折算倍率改变后，必须重新校验所有道路坐标和最优路线。
- 行程事实只描述已经选出的路线，展示层不能反向改变选路结果。
- 世界核心已经执行本目录声明的选路与十二项指标规则；行路玩法只在规划成功后原子更新人物位置，不保存耗时与行程进度。
