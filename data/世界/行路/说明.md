# 行路数据包

本包按组件维护数据，文件归属由 [组件.json](组件.json) 声明。数据集名是公共读取契约；编号、池文件名不随目录变化。

## 功能

### 一、启动期把规则读死

1. **规划器入口**：世界核心在启动的最后一步，用坐标边界、每格米数、地表高度、区域表、地形表、地点表与道路构造行路规划器；所有校验都发生在构建这一步，任何一条不满足都让世界核心启动失败。
2. **两组数据必须齐备**：行路规则、行程展示、道路通行规则、地形通行规则与行程指标定义五份数据缺一份就抛「缺少 xxx.json」。（`规则/行程.json`、`规则/道路通行.json`、`规则/地形通行.json`、`展示/行程.json`、`定义/行程指标.json`）
3. **相邻步硬校验**：坐标规则里的 `允许相邻步` 必须恰好是 8 个不含原点的偏移且互不重复，否则抛「允许相邻步必须完整且唯一地定义八方向」；`斜向距离倍率` 必须是正数（1.4142135623730951）。（`规则/行程.json`）
4. **路网规则硬校验**：`默认双向` 与 `道路边类型唯一` 必须是 true；`允许非道路通行` 与 `道路覆盖地形` 必须是布尔值；`非道路地形倍率` 必须是「两端平均」，否则拒绝启动。（`规则/行程.json`）
5. **自动选路排序硬校验**：`自动选路` 里的 `排序` 必须逐条等于（折算路程，升序）、（道路段数，升序）、（水平距离，升序），顺序或指标不符就报错。（`规则/行程.json`）
6. **折算系数硬校验**：`路程折算` 里的 `取整` 必须是「四舍五入」；`水平每米` 1、`上升每米` 8、`下降每米` 3 必须是正数。（`规则/行程.json`）
7. **倍率覆盖校验**：道路与地形两张倍率表都必须是字典列表，名称非空且不重复，`倍率` 必须为正数；道路倍率名集合必须与世界实际用到的道路类型集合完全相等，地形倍率名集合必须与地形分区实际使用的地形集合完全相等，多一个少一个都报错。（`规则/道路通行.json`、`规则/地形通行.json`）
8. **指标契约校验**：行程指标定义里的 `名称` 与 `单位` 必须按固定顺序与引擎内定的十二项完全一致（水平距离/米、道路段数/段、地形段数/段、最低海拔/米、最高海拔/米、累计爬升/米、累计下降/米、最大单步升高/米、最大单步降低/米、最大上坡千分比/千分比、最大下坡千分比/千分比、折算路程/米），改名、换单位或调序都报错。（`定义/行程指标.json`）

### 二、叙事数据的启动期校验

9. **展示限制与距离**：`展示限制` 里的 `最多通行段` 4 与 `最多经由地点` 3 必须是正整数；`距离` 里的 `每里米数` 500 与 `约数步长` 10 必须是正整数。（`展示/行程.json`）
10. **叙事顺序**：`叙事` 里的 `顺序` 必须完整且唯一地是「起程 / 通行 / 经由 / 途中 / 地势 / 抵达 / 总览」七段，缺项、重复或多出都抛「行路展示.叙事.顺序必须完整且唯一地定义七段叙事」。（`展示/行程.json`）
11. **叙事文本非空**：`通行分隔`、`通行省略`、`经由`、`经由省略后缀`、`地势`、`总览高地`、`总览低地` 必须是已存在的非空字符串；`地形措辞` 必须是带 `起行` 与 `转入` 的对象。（`展示/行程.json`）
12. **方向措辞全覆盖**：`方向措辞` 的每一项 `方向` 必须是两个整数组成的坐标差，键集合必须恰好等于 `允许相邻步`，措辞非空且不重复。（`展示/行程.json`、`规则/行程.json`）
13. **道路措辞全覆盖**：每条 `道路措辞` 必须带非空 `起行` 与 `转入`，道路名不重复，键集合必须恰好等于道路通行规则里的道路集合。（`展示/行程.json`、`规则/道路通行.json`）
14. **分档措辞**：`爬升措辞` 按 `累计爬升上限`（500 / 3000 / 8000 / 15000）分档，`海拔措辞` 按 `最高海拔上限`（0 / 3000 / 8000 / 15000 / 22000）分档；阈值只许整数或空值，有限阈值必须严格升序且不重复，最后一档必须以空值兜底，措辞必须非空。（`展示/行程.json`）
15. **境界行路一一对应**：`境界行路` 每项必须带非空 `方式`、`起程`、`途中`、`抵达`，境界编号不得重复；编号集合必须与境界数据集的全部实体完全一致，每个境界必须有名称，且 20 条的「方式 + 三段叙事」四元组必须互不重复。（`展示/行程.json`）

### 三、路线怎么算出来

16. **入口校验**：规划要求起点与终点不是同一坐标（否则抛「起点与终点不能是同一坐标」），境界编号必须已在 `境界行路` 中登记（否则抛「境界没有行路叙事」）。
17. **最短路搜索**：路线按代价最小逐步扩展，搜索状态是「当前坐标 + 上一条道路类型」，取路顺序为折算路程、道路段数、水平距离三级升序，与 `自动选路` 的 `排序` 一致。（`规则/行程.json`）
18. **边与邻居**：每一步只走 `允许相邻步` 的八个偏移且必须落在坐标边界内；道路类型按无向边查表；这一步没有道路且 `允许非道路通行` 为假时跳过；搜不到终点就抛「地图规则下不存在可达行程」。（`规则/行程.json`）
19. **单步代价**：水平距离 = `水平每格米数` × `斜向距离倍率`（斜向步）或 × 1（直向步）；通行倍率在 `道路覆盖地形` 为真时直接取道路倍率，否则取两端地形倍率的平均再乘道路倍率；折算路程 = 水平距离 × 通行倍率 × `水平每米`，上坡再加 `升高 × 上升每米`，下坡再加 `降低 × 下降每米`。（`规则/行程.json`、`规则/道路通行.json`、`规则/地形通行.json`）
20. **道路段数**：当前步有道路且类型与上一条不同时道路段数加一，同类型连续行走只算一段，作为第二比较键。
21. **通行段分组**：把相邻步骤按「类型 + 名称」合并成段；道路段用道路名，其余用落点地形名；方向取首末坐标差的正负号；段的水平距离按四舍五入取整。
22. **十二项指标**：一趟遍历算出全部指标，其中上坡与下坡千分比 = 四舍五入（爬升或下降 × 1000 ÷ 该步水平距离）；最大单步升降与最大坡度在没有步长时取 0；道路段数与地形段数由通行段按类型计数。（`定义/行程指标.json`）
23. **经由地点**：取路线内部坐标命中的已登记地点名，按首次出现去重，作为经由地点；起点与终点本身不计入。

### 四、七段叙事怎么生成

24. **起程与抵达**：起点与终点用地点名，未登记地点退化为「区域·地形（横坐标, 纵坐标）」，再套入该境界的 `起程` 与 `抵达` 模板。
25. **通行与经由**：通行段按 `最多通行段` 截断，首段用 `起行`、其后用 `转入`，超出上限追加 `通行省略`，各段之间用 `通行分隔` 连接；经由地点取前 `最多经由地点` 个用「、」连接，超出时追加 `经由省略后缀`，一个都没有时按 `没有经由地点` 输出。（`展示/行程.json`）
26. **地势**：转折点取路线内部段中海拔最高的点（没有内部段时就在整条路线上找），再套 `地势` 模板与按 `累计爬升` 分档的 `爬升措辞`。（`展示/行程.json`）
27. **总览**：里程 = 水平距离 ÷ `每里米数` 后按 `约数步长` 四舍五入且下限为一步；`最高海拔` 大于 0 选 `总览高地`，否则选 `总览低地`，海拔措辞按 `最高海拔` 分档。（`展示/行程.json`）
28. **输出**：叙事只按 `叙事` 里的 `顺序` 输出非空段，空段（例如没有经由地点）直接省略；路线、通行段、经由地点、指标与叙事一并装进一份行路方案返回。

### 五、行路玩法的调用顺序

29. **玩法启动依赖**：行路玩法启动要求世界核心、角色核心、玩家位置核心、行动编排核心、人物状态核心五个已就绪，缺一个就拒绝启动并指出「…必须先于行路玩法启动」。
30. **目的地参数**：目的地只接受一个地点名或一组两个整数坐标，其余写法抛「目的地只能写地点名或一组 xy 坐标」，坐标解析失败抛「坐标必须写成两个整数」。
31. **发起条件**：先向行动编排核心取参与者，跟随身份抛「当前正在跟随领队，只有领队可以发起行路」；再对每个参与者做「自主空闲且可行动」的授权检查，任一不通过就整单拒绝；非地表空间抛「当前身处宗门洞天…」。
32. **规划与落点**：行路玩法用人物当前的境界编号与当前坐标去调世界行路的规划，规划异常统一转成行路查询错误（起点与终点同坐标换成「你已经身在此处，无须再次动身」）；随后把规划出的目的地坐标交给玩家位置核心做一次集体行路事务，冲突转成行路冲突，事务重放由重放标记标出。
