# 行路定义关系说明

> 本说明只写现行规则与边界；历史变更与试玩过程见 [待补内容.md](../../../战斗/内容/待补内容.md)。

本目录只登记一段完整行程可以计算和展示哪些稳定事实，不保存具体道路、选路参数或展示文本。

## `行程指标.json`

登记道路段数、地形段数、水平距离、最低和最高海拔、累计爬升和下降、最大单步升降、最大上下坡千分比与折算路程。

```text
道路.途经坐标
+ 地势.地表高度
+ 地势.水平每格米数
+ 世界/行路/规则/行程.json.路程折算
+ 世界/行路/规则/道路通行.json
+ 世界/行路/规则/地形通行.json
-> 完整行程指标
-> 自动选路与行程展示
```

这些指标描述旅途，不限制人物。最高海拔、坡度和爬升可以进入行程文本或路线权重，但不得直接成为境界准入条件。

## 修改检查

- 指标名称必须与 `世界/行路/规则/行程.json` 和 `世界/行路/展示/行程.json` 使用的名称一致。
- 单位统一使用米、段和千分比，不在道路内容中复制派生数值。
- 新增指标时必须说明它来自道路、地势还是路线组合。
- 本目录不登记人物能力，也不建立境界与地点可达性的关系。
