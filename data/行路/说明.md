# 行路数据包

本包按组件维护数据，文件归属由 [组件.json](组件.json) 声明。数据集名是公共读取契约；编号、池文件名不随目录变化。

## 数据集

| 数据集 | 本包路径 |
| --- | --- |
| 行路定义 | `定义/*.json` |
| 行路规则 | `规则/行程.json` |
| 道路通行规则 | `规则/道路通行.json` |
| 地形通行规则 | `规则/地形通行.json` |
| 行路展示 | `展示/*.json` |

## 领域说明

- [定义/说明.md](定义/说明.md)
- [展示/说明.md](展示/说明.md)
- [规则/说明.md](规则/说明.md)

修改前阅读对应领域说明；新增文件更新本包清单。只在基础读取入口登记新组件，不把玩法规则放入基础。
