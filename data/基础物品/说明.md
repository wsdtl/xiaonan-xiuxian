# 物品数据包

本包按组件维护数据，文件归属由 [组件.json](组件.json) 声明。数据集名是公共读取契约；编号、池文件名不随目录变化。

## 数据集

| 数据集 | 本包路径 |
| --- | --- |
| 物品规则 | `规则/分类.json` |
| 物品规则 | `规则/品级.json` |
| 物品定义 | `定义/*.json` |
| 纳戒展示 | `展示/*.json` |
| 灵植 | `内容/灵植/灵植-*.json` |
| 灵矿 | `内容/灵矿/灵矿-*.json` |
| 兽宝 | `内容/兽宝/兽宝-*.json` |

丹药不在本包：359 个丹药实体与丹方由 [炼丹](../炼丹/说明.md) 组件解释，路径为 `data/炼丹/内容/丹药`。
