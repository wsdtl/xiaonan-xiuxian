# 战斗展示

`战报.json`是战斗事实到玩家战报的唯一展示契约。

```text
BattleEngine 结构化结果
+ 战斗/定义/{属性,资源,事件}.json
+ 技能、状态与构筑的展示名称
+ 战斗/展示/战报.json
-> 标准化战报
-> 后端战报展示协议
-> static/battle-report
```

| 根部分 | 作用 |
| --- | --- |
| `协议` | 战报 Schema、展示协议和展示版本 |
| `游戏名称` | 战报对外显示的游戏名 |
| `视觉` | 前景色、系统色、参战者颜色和资源颜色 |
| `标准化` | 原始事件到分类、名称和明细格式的映射 |
| `展示` | 界面文案、顺序、状态和结果表现 |

`标准化.结算事件`只选择哪些已有事件代表最终伤害、战场伤害、资源恢复、资源消耗和状态增减，不能新增结算。事件是否触发、属性数值、目标和胜负都由战斗核心决定。

修改事件、资源或界面字段时，必须同步初始化战斗核心并重新生成战报；静态页面只能读取后端展示协议，不能自定义游戏文案或分类。
