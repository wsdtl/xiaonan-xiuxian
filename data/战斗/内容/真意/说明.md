# 真意 JSON 关系说明

真意是修士在修行与战斗中领悟的被动战斗规律，使用 `41` 前缀编号。当前 68 套构筑、408 道真意。真意归角色自身承载，不依附本命武器，也不占用器律位置。

## 结构关系

```text
真意实体
-> 恰好一项被动技能
-> 效果[] 全部是监听事件节点
```

真意没有主动技能，不形成完整功法循环。被动技能与监听节点必须符合 `战斗/定义/原子能力.json`，所监听事件必须存在于 `战斗/定义/事件.json`。真意的监听效果**直接写在能力树里**，能力树不定义新的战斗语义或玩家显示名称。

## 与其他 JSON 的关系

- 各角色自身 JSON 中的 `修行槽位.真意` 决定角色真意槽数量；本命武器只承载器律；
- `基础/定义/品级.json` 为真意实例提供独立品级；
- 玩家从全部 408 道真意按编号取用，不维护额外的全池 JSON；
- 道侣实体用 `构筑` 引用构筑模板，模板的 `真意` 列表固定编号；种族不参与构筑；
- 敌方修士用 `构筑` 引用模板，按自己的 `修行槽位` 取真意；
- 灵兽没有构筑，不出真意实例。

真意不保存评分、方向、分类标签或词条表。每道真意在实体根节点保存自身逆权重；同一编号无论装配到谁身上，正文与权重都完全相同。

## 构筑直配

数据里没有 `池/` 目录，也不再有道侣个人池、敌人阶段池或灵兽池。

- 道侣用 `构筑` 引用模板，模板的 `真意` 列表是稳定编号，不随机重抽；
- 敌方修士用 `构筑` 引用模板，按自己的 `修行槽位` 取卡；灵兽没有构筑；
- 玩家装配时从全部真意实体按编号取用，品级由实例单独决定。

## 监听时点

真意是**战场叙事**，观察范围覆盖整个战场：行动开始/结束、命中/暴击/格挡的判定前后与闪避后、技能施放后/失败后、资源消耗前、恢复前后、添加状态后、获得护盾后、击杀后、造成伤害后、受到伤害后、战斗对象退场后。

当前 408 道真意各一条监听，共 20 个时点；器律 64 张、65 条监听、17 个时点；两者交集 11 个时点，是分工不是子集。

## 修改检查

- 编号必须使用 `41` 前缀。
- 权重必须是正整数；同名实体权重必须一致，异名实体权重不得重复。
- 根能力必须是被动技能，且恰好一项；效果里出现主动技能或非监听节点都属于越界。
- 每道真意自己携带完整效果树；不得复制其他真意的实际构筑，也不靠改名制造新效果。
- **计量与状态的名字逐条真意唯一**：名字 = 真意名前缀 + 场景词（`返真/养真/意痕`），全库不重名，也不引用别的真意定义的名字；改名前先全库检索。
- 改真意编号时同步检查构筑模板的 `真意` 列表；模板被哪些道侣/敌人引用，由实体上的 `构筑` 编号反查。
