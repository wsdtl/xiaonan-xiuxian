# 功法 JSON 关系说明

功法是完整战斗循环的二次对象，使用 `40` 前缀编号。当前 30 个分类池、600 门功法。

## 结构关系

```text
功法实体.能力
  ├─ 主动技能 -> 精神消耗、冷却行动、目标与效果
  └─ 被动技能 -> 监听节点，按事件响应
```

主动技能和被动技能根节点来自 `战斗/定义/原子能力.json`。功法内容可通过战斗构筑模板保存嵌套效果；数据装载时展开模板，再由战斗核心按完整能力树执行。模板只复用效果正文，不代替原子能力语义，也不承载玩家可见名称。属性、资源和事件名继续受战斗定义约束。

- **必须至少有一项主动技能**：功法承载完整战斗循环，只有被动的卡片应当做成真意。
- 被动技能的每个效果都必须是 `监听事件` 节点，战斗核心只登记监听节点；写在被动槽位里的其他能力不会生效，由 `tools/架构审查/检查构筑形状.py` 报出。
- 状态、规则和判定等节点由原子能力字段规约约束；同一功法内不允许出现两道同名异义的设计。
- **计量与状态的名字必须逐卡唯一**：名字 = 卡名前缀 + 场景词（`九转归元`、`不灭养元`），全库不重名。`tools/架构审查/检查词条作用域.py` 会报出撞名；另外还有一条命名测试把这条锁死。名字只描述这张卡自己的池子，不许引用别的卡定义的名字。
- `判定`（`命中/暴击/格挡/控制/连击/反击/任意`）和 `规则`（`修改战场规则.名称`）是引擎按名字取用的口令，不按卡改名。

## 与其他 JSON 的关系

| 关系 | 数据 |
| --- | --- |
| 能力词汇表 | `战斗/定义/原子能力.json` |
| 品级倍率 | `基础/定义/品级.json` |
| 角色修行槽位 | 各角色自身 JSON 中的 `修行槽位.功法` |
| 构筑相冲 | `战斗/规则/构筑/相冲.json` |
| 精神、冷却、行动 | `战斗/定义/资源.json`、`战斗/规则/行动.json` |
| 玩家候选池 | 解析全部功法实体文件后按编号合并的虚拟全池，不维护全池 JSON |
| 道侣候选池 | `池/道侣/` 下按道侣编号命名的个人池 |
| 敌人候选池 | `池/敌方修士/` 下六个阶段源池 |
| 灵兽候选池 | `池/灵兽/` 下六个阶段源池 |

功法不保存评分、方向或兼容标签。每门功法在实体根节点保存自身逆权重；玩家从解析器合并去重后的全部功法中按权重随机。定向池不复制实体：道侣个人池直接保存功法编号字符串，敌人阶段池直接保存源池文件名字符串。

## 两仪双相

只有明确编写两仪分支的少数功法可以读取修士性别。男性运转乾相，女性运转坤相；两相必须具有相同效果数量和接近的战斗预算，只改变战斗节奏，不改变能否修炼、装配槽位或功法权重。

两仪分支必须通过通用 `类型条件` 读取战斗快照的性别，不得为某门功法增加专用执行器。性别为空的参战者不命中乾相或坤相；不允许按敌方性别增加伤害，也不允许男性或女性专属修炼。

## 定向随机池

三个池目录各管一件事。**根节点一律是字符串列表**，不为每个字符串再套 `编号` 或 `资源池` 字典，也不复制实体定义、名称、评分、权重或方向标签。

- `池/道侣/`：不保存公共总池。264 名道侣各自一份以「道侣编号-功法池」命名的个人池，每份 24 个稳定编号，文件名不含可变的角色名称。选材由称号、地点坐标解析出的区域地形与姓名意象共同决定，同类再按能力树与称号需要的支援、护持、控制、节奏或杀伐倾向挑选；运行时以道侣实体的 `功法池` 引用定位。**不得用全库随机或公共道侣池作隐式兜底**。
- `池/敌方修士/`：按初窥、登堂、入微、圆融、镇域、天灾拆成六份独立源池，由 `角色/规则/主体/敌方修士.json` 各阶梯的 `功法池` 引用，偏向杀伐、压制、控制和反制。池内直接保存 `功法-*` 实体源文件名字符串；数据服务递归展开并校验编号，按调用方选择保留重复或按编号去重。
- `池/灵兽/`：同样按六阶拆分，由 `角色/规则/主体/灵兽.json` 的 `功法池` 引用；候选避开刀、剑、枪等明显依赖修士兵器的分类，依次侧重肉身扑杀、行气、元素毒雷、御灵和高阶绝境能力。
- 敌人阶段池**不继承上一阶段**，业务只展开当前阶段文件列出的源池；新增、删除或改名源池时必须同步更新阶段池。

## 修改检查

- 编号必须使用 `40` 前缀且全库唯一。
- 权重必须是正整数；同名实体权重必须一致，异名实体权重不得重复。
- 必须至少有一项主动技能；被动技能的每个效果都必须是 `监听事件`。
- 能力树里每个节点都必须对应 `战斗/定义/原子能力.json` 的已登记能力，节点字段符合该能力的字段规约。
- 修改本功法涉及的设计时重新检查 `战斗/规则/构筑/相冲.json`。
- 新增、删除或改名源池时同步更新敌人阶段池；改功法编号时同步检查道侣个人池。
- 改功法名称不会改变身份；改编号则会破坏实例和存档，禁止修改。
- 增加新字段前先在原子能力 Schema 中证明它属于通用语义。
