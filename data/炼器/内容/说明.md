# 炼器内容

`器律-*.json` 是可锻入本命武器的具体器律。每条器律使用六位稳定编号，声明所需器阶、铸法、兽引和战斗能力。

器律只引用 `内容/战斗机制` 的既有机制。炼器服务负责校验兽宝、灵矿和四孔覆炼；战斗核心只按器律编号装载最终能力，不读取锻造材料。

当前首批 64 条器律按战斗用途拆成八个文件，每个用途均覆盖灵器、法器、法宝和后天灵宝。后续增加器律只需增加 JSON 实体并引用已登记铸法与战斗机制。

`池/` 按器阶保存四个编号池，每池 16 条器律，并完整覆盖对应器阶。自动生成本命武器时，第一至第四孔依次从灵器、法器、法宝和后天灵宝池抽取；玩家主动炼器仍然按器律编号选择，不受随机池限制。
