# 一次性迁移脚本

本目录保存**已经执行完毕**的数据树一次性改写脚本。它们不是可重复运行的维护工具，
不能当作日常审查入口使用。

保留原因只有一个：记录数据是怎么变成现在这样的，便于回溯某次改动的具体规则。
脚本依赖迁移前的数据形态，现在的数据上重跑要么无效果，要么会造成损坏。

| 脚本 | 做过什么 | 重跑后果 |
| --- | --- | --- |
| `migrate_component_data.py` | 按组件重排数据树，产出本目录的 `组件迁移清单.json` | 依赖 `git ls-files`，当前环境没有 git；会重写组件清单 |
| `split_item_components.py` | 把旧「物品」拆成「基础物品」与「炼丹·丹药」 | **会 `rmtree` 现有目录，禁止重跑** |
| `rollback_item_split.py` | 上面那步的回滚 | **会把「丹药」搬回并删掉「基础物品」，禁止重跑** |
| `rename_medicine_pool_field.py` | 全库重命名一个池字段 | 字段已改名，重跑无效果 |
| `update_component_navigation.py` | 生成组件导航并修复搬迁后的 Markdown 链接 | 链接已修好，重跑无效果 |
| `内联战斗机制.py` | 把 `引用战斗机制` 中间层内联进卡片，并清理旧属性名与失效说明 | 机制库已删除，脚本退化为残留检查 |
| `重命名词条.py` | 把计量/状态两个词条池改成逐实例唯一、贴合卡片的名字（含说明改写） | 名字已唯一，重跑会把新名字再改一遍，禁止重跑 |
| `修整词条前缀.py` | 上一版用 2→3→4 字前缀阶梯，3 字切在词中间；这一步按偶数阶梯（2→4→6→全名）重排 472 个名字 | 已全是偶数前缀，重跑无效果 |
| `清理冗余判定.py` | 生成器给条件结算套了「条件执行 → 尝试执行 → 再判一次同条件」的三层壳；拆掉重复的那次判定，保留 `尝试执行` 外壳与两条分支 | 已无重复判定，重跑无效果 |
| `裁掉规则正文.py` | `说明` 里原本另存一份规则正文；正文改由渲染器现算后，把 `说明` 裁到只剩卡头 | 说明只剩卡头，重跑无效果 |
| `补险注状态.py` | 给读「险注」层数的 36 张卡补上那个缺失的层数状态（各造一个本卡专属状态 + 累积点 + 改指读取） | 已补完，重跑无效果 |
| `补缺失状态.py` | 通用版：给「被增删改查、从来没被创建」的状态补定义，116 张卡 / 121 对 / 113 个累积点 | 剩下的 20 个悬空需人工定位，重跑无效果 |
| `补目标层数状态.py` | 收掉那 8 张「只读目标身上层数、没人上过状态」的卡：在含读取的主动技能效果列表最前面插一个 添加状态（目标=当前目标） | 已补完，重跑无效果 |
| `接满条转锋.py` | 把 5 张卡「满条转锋」读的老「势」接到本卡自己的蓄积计量上（蓄＝蓄积） | 已接完，重跑无效果 |
| `补最后引用.py` | 给「只读不建」的引用补建立节点：状态→添加状态、事实→记录战斗事实、关联→修改战斗关联。战丹/伤势跳过（战前装配，插了会崩） | 已补完，重跑无效果 |
| `清惰性节点.py` | 删掉 632 个惰性节点（无载荷、无人读的状态与计量，含级联摘掉的空壳）。完整清单落在本目录的 `清惰性节点清单.txt`，以后印卡补内容照它看哪张卡空着哪些格子。**原子能力注册表一条没动** | 已无惰性节点，重跑无效果 |

日常审查和验证入口在上一层：

```powershell
.venv/Scripts/python.exe -X utf8 tools/架构审查/检查边界.py
.venv/Scripts/python.exe -X utf8 tools/架构审查/检查构筑形状.py
.venv/Scripts/python.exe -X utf8 tools/架构审查/检查词条作用域.py
.venv/Scripts/python.exe -X utf8 tools/验证契约引擎.py
```

改动战斗数据前后，用两份对照取行为基线。**两条通道都要跑**——构筑走 `CombatBuildRef`，战丹与长期伤势走 `prepared_statuses`，只跑一条会留盲区：

```powershell
# 构筑侧（功法/真意/器律，1264 场）
.venv/Scripts/python.exe -X utf8 tools/语料对照.py _改前
# 战前状态侧（战丹/长期伤势，170 场）
.venv/Scripts/python.exe -X utf8 tools/战前状态对照.py "<改动前的 data 目录>"
```

`组件迁移清单.json` 是 `migrate_component_data.py` 的产物，只用于那次验收，不冻结后续合法编辑。
