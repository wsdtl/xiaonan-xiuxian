# 行为验证脚本

共 **11 支**。

- `验证QQWebSocket.py`：启动一个真的 WebSocket 服务端（回环地址），让真实驱动器按 `.env` 的
- `验证QQWebSocket关闭码.py`：主端到端验证在 `验证QQWebSocket.py`（握手、鉴权、心跳、派发、回复）。本文件
- `验证QQ传输开关.py`：驱动器清单由代码登记，配置只决定 QQ 走哪一种入站方式。这个开关决定了
- `验证QQ双驱动器生命周期.py`：`.env` 允许 webhook 与 WebSocket 同时启用。两者共用 `qq_protocol` 的模块级
- `验证启动顺序.py`：`game/app.py` 把微服务装配挂在 `OnEvent.connect(priority=1000)` 上，命令回调
- `验证契约引擎.py`：`game/core/data/schema.py` 是通用校验引擎，`game/core/combat/schema.py` 是它的
- `验证控制台媒体.py`：`ConsoleMediaStore` 负责把消息里的四类图片来源（空值、字符串、Path、字节）统一
- `验证物品契约.py`：`data/物品/基础物品` 的 `分类.json`、`公共字段.json` 与 `使用效果.json` 声明了丹药
- `验证组件契约.py`：非战斗侧全部实体类别已接入字段契约：境界、伤势、人物状态、阵法、先天灵宝、
- `验证规则层.py`：`检查规则层.py` 只核「登记与实现不脱钩」，它跑不动战斗。规则层是行为，所以另有一条
