# 工具目录

只放游戏外校核脚本，不放游戏数据。统一跑法：

```powershell
.venv/Scripts/python.exe -X utf8 tools/全量核对.py
```

## 必过闸门（9 项）

| 项 | 脚本 | 挡什么 |
| --- | --- | --- |
| 边界审查 | `架构审查/结构/检查边界.py` | 跨层导入、动态导入失控、微服务包缺必备文件、中文标识符、硬编码数据目录 |
| 启动契约 | `架构审查/命令/检查启动契约.py` | 命令重复注册、守卫规则悬空 |
| 数据驱动 | `架构审查/数据/检查数据驱动.py` | 正式 JSON 没有规则匹配、规则/文案没人读、说明与数据脱节 |
| 存档键名 | `架构审查/数据/检查存档键名.py` | 存档键不是编号形态 |
| 存档版本 | `架构审查/数据/检查存档版本.py` | 存档读出来不是当前版语义 |
| 数据不被写回 | `架构审查/数据/检查数据不被写回.py` | 运行期改写正式 JSON |
| 启动顺序 | `行为验证/驱动/验证启动顺序.py` | 驱动器早于业务服务启动 |
| 语法 | `compileall` | 语法错误 |
| 单元测试 | `跑测试.py` | 数据装载、字段契约、守卫、战斗入口、战报、战前状态 |

`跑测试.py` 把 `tests/` 分片并发跑，每个进程用临时数据库，不碰真实存档。

## 约定

- 临时件落 `_输出/`（已忽略）；不要往仓库根丢临时文件。
- 判据非零退出即失败；判据挡下改动时先改做法，不改判据口径。
- 只保留能挡住启动失败、存档损坏、边界穿透、正式数据被写回的判据；其余一次性修补、页面细节、内容集中度不再设长期判据。
- 历史方案、施工单与旧基线在 git 历史里；本目录不再保存。
