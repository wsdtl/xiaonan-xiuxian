## 可靠改法（这几轮踩坑总结，照着做）

1. **一次只改一处**，用 read 读原文再 edit；不要在一个程序里塞多段大模板串；
2. **程序字符串里不写尖括号**（TS 会当类型断言）——要写得用 `String.fromCharCode(60/62)`；
3. 不用"生成 Python 脚本再跑"这条路改源码（已连栽多次）；
4. 每改完一处编译一次；一批改完跑三证再提交。
