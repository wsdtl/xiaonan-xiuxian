# 原子能力全景与用法对照

> 委托方指出：旧设计对机制的理解比我强。读完旧卡我承认——旧设计用「设置资源清零」「抢归属」
> 「复活」「切换形态」，我只会「加属性、打伤害」。这份表把 65 种能力按「改变什么战场事实」摆开。

## 一、九类能力

| 类 | 数量 | 能力 |
| --- | --- | --- |
| 装配 | 4 | 规则文本、固定属性加成、主动技能、被动技能 |
| 组合 | 7 | 顺序、条件、随机、遍历、重复、尝试、事务 |
| 触发 | 1 | 监听事件 |
| 数值 | 4 | 读取、计算、随机、聚合 |
| 目标 | 3 | 选择目标、选择技能、选择状态 |
| 条件 | 6 | 概率、数值、状态、类型、组合、标签 |
| **效果** | **40** | 见下 |

## 二、40 种效果按「改变什么」分七组

### A. 改数值（最浅）
`造成伤害` `恢复资源` `消耗资源` `支付代价` `追加攻击` `分摊伤害` `转移伤害`

### B. 改资源（比改属性狠）
`设置资源` `转移资源`
→ 旧设计用它把对手精神**直接清零**，等于废掉对手的技能

### C. 改状态
`添加状态` `移除状态` `修改状态层数` `修改状态持续` `复制状态` `转移状态`
→ 旧设计用「移除状态 选择全部」一次清光己方全部负面

### D. 改场面结构（旧设计的精髓，我完全没用）
`创建战斗对象` `移除战斗对象` `修改归属` `复活` `切换形态`
→ 抢敌方构造物、复活死亡单位、战斗中途变形

### E. 改规则与判定
`修改判定` `修改战场规则` `修改事件数值` `修改事件目标` `修改事件标签` `取消事件` `转化事件`
→ 直接干预结算，比加减属性高一档

### F. 改技能与构筑
`修改技能` `复制技能` `触发技能` `修改技能冷却` `修改构筑计量` `修改行动条` `修改行动意图` `修改战术`
→ 旧设计给全部技能追加目标标签

### G. 记录与复用
`记录战斗事实` `保存结果` `回放效果` `修改战斗关联` `抵挡致命伤害`

## 三、我用过的（对照）

| 组 | 我用了 | 占比 |
| --- | --- | --- |
| A 改数值 | 造成伤害、恢复资源 | 2/7 |
| B 改资源 | 支付代价 | 1/2 |
| C 改状态 | 添加状态 | 1/6 |
| D 改结构 | **0** | 0/5 |
| E 改规则 | **0** | 0/7 |
| F 改技能 | 修改技能冷却 | 1/8 |
| G 记录复用 | **0** | 0/5 |

**40 种效果我只用了 5 种，D/E/G 三组一次没碰。**

## 四、重设计的方向

每套功法至少要有**一本**动 D 组（改场面）或 E 组（改规则），否则就是数值堆。

| 流派类型 | 该动的组 |
| --- | --- |
| 召唤类 | D（创建/移除/修改归属） |
| 控制类 | C + E（修改判定） |
| 反制类 | E（取消事件/转化事件） |
| 形态类 | D（切换形态） |
| 资源类 | B（设置/转移资源） |
| 记录类 | G（记录 + 回放） |
