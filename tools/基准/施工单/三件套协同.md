# 三件套协同：功法 / 真意 / 气机是一个系统

> 委托方指出：我在给自己套框框——功法 6 本、真意 6 条、气机 6 个，各填各的。
> 正确做法是：三者组成**一个整体**来完整制敌。气机会重复不要紧，它本来就是线性组合。

## 一、三者的角色不是并列，是咬合

| 件 | 角色 | 回答的问题 |
| --- | --- | --- |
| **功法** | 主动制造事件 | 我怎么打出去 |
| **真意** | 被动响应该事件 | 这件事发生之后，我再做什么 |
| **气机** | 放大该事件的收益 | 这件事的产出，怎么变成更大的数 |

**三者串起来才是一条完整的链**：

```
功法制造事件 → 真意接住事件 → 气机把收益放大 → 回到功法
```

## 二、反面：我之前怎么做的

- 功法：六本各打各的（生存、输出、暴击、速度…）
- 真意：六条各响各的（命中后、闪避后、格挡后…）
- 气机：六组属性各补各的（攻/防、暴/暴伤…）

**三份清单互不相干**，所以一套流派打起来是「六个独立技能 + 六个独立被动 + 六个属性包」，
没有形成合力。玩家感受不到「这套打法的核心思路」。

## 三、正面：守土应该这样咬合

**核心机制：格挡 → 攒势 → 反击**（一句话能说清的循环）

| 件 | 在循环里的位置 | 具体 |
| --- | --- | --- |
| 功法·山岳桩 | 制造格挡形态 | 换桩后防御降、格挡减伤升 |
| 功法·卸力诀 | 制造「打不中」 | 命中判定必败，逼对手换招 |
| 真意·承力 | 接住格挡 | 格挡后叠「势」层 |
| 真意·应手 | 接住格挡 | 格挡后立即还击 |
| 气机·卸力气机 | 放大格挡 | 格挡率 + 格挡减伤 |
| 功法·镇岳诀 | 收口 | 把攒的势一次放出去（精神清零） |

**六本功法 + 六条真意 + 六个气机，全部绕着「格挡→攒势→反击」转。**

## 四、检验标准

> 把一套流派的三件套念给一个没玩过的人听，他能不能一句话说出「这套怎么赢」？

| 套 | 一句话 |
| --- | --- |
| 守土 | 站着挨打，攒够了再一下把对手打空 |
| 抢攻 | 抢第一次出手，一套连招打死 |
| 锁链 | 先用丝控住，再慢慢收口 |
| 焚血 | 割自己的血，换一次重击 |

**说不出来 = 三件套没咬合。**

## 五、气机可以重复

气机是线性属性组合，同一套流派里出现「攻击+暴击」和「暴击+暴伤」是正常的，
因为它们服务的是同一个循环的不同环节，不是六个独立设计。

**判据不是「六个气机各不相同」，是「六个气机是否都在放大同一条链」。**
