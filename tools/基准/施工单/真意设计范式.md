# 真意设计范式（重写）

> 委托方批评：真意被动技能「素、平平无奇、没有对策性、纯状态类、没有交互」。
> 这条批评对。我写的真意全是「某事件之后，给自己加一点属性」，那不是对策，是自动挂机。

## 一、游戏王的精髓是什么

不是「效果多」，是**在对手的动作上开窗口**：

| 游戏王做法 | 对应到这里 |
| --- | --- |
| 对手召唤时，我发动陷阱 | 监听**对手**的事件，而不是自己的 |
| 这张卡不会被效果破坏 | 规则层的免疫（已经有了） |
| 连锁：我响应你的响应 | 监听事件里再触发效果 |
| 支付代价换取一次机会 | 自损换行动/必中/破防 |

**关键差别：监听谁。** 我现在的六条真意，监听的都是「自己做了什么」，
所以它们只是在自动加速；真正的对策要监听「对手做了什么」。

## 二、六条真意的新分工

每个流派的六条真意，按下面的角色分配，**不允许六条都是同一种**：

| 角色 | 监听什么 | 效果该是什么 | 条数 |
| --- | --- | --- | --- |
| **截** | 对手起手（技能施放前/命中判定前） | 打断、削命中、推对手行动条 | 1 |
| **夺** | 对手获得资源/护盾/状态 | 夺取、削减、转为己用 | 1 |
| **反** | 自己受击/被控/被削 | 立刻还手、解控、反伤 | 1 |
| **换** | 自己付出代价（掉血/掉魂/弃牌） | 换一次额外行动或必中 | 1 |
| **势** | 局面条件（对手残血/自己残血/人多） | 条件满足时解锁强力效果 | 1 |
| **连** | 自己达成某种条件后 | 触发一次追加（真正的连击） | 1 |

## 三、可用的原子能力

| 目的 | 能力 |
| --- | --- |
| 打断 | `修改技能冷却`（加对手 CD）、`添加状态`（降对手命中/攻击） |
| 夺取 | `移除状态`、`修改资源`、`转移状态` |
| 反制 | `造成伤害`、`添加状态`（给对手负面） |
| 换机会 | `修改行动条`（推自己） |
| 条件 | `条件执行` + `数值条件` / `状态条件` / `类型条件` / `标签条件` |

## 四、写一条真意的模板

```
时机：当 <谁> <做什么> 时
条件：<局面条件，可选>
动作：<干预对手 / 换取机会>
限制：<每场几次 / 冷却 / 代价>
```

**判定标准**：把这条真意的效果删掉，战斗会不会不一样？
如果只是「少加 8 点攻击」，那就是素的，重写。

## 五、反面例子（我现在写的）

```
时机：造成伤害后
动作：自己攻击 +8，持续 1 行动
```

删掉它，战斗只是慢一点，节奏不变。**这就是素的。**

## 六、正面例子（该写成这样）

```
时机：对手施放技能前
动作：该技能冷却 +2 行动
限制：每场两次
```

```
时机：对手获得护盾后
动作：该护盾减半，减掉的那部分转为自己的护盾
```

```
时机：自己受到控制后
动作：立刻解除该控制，并对施加者造成一次伤害
```

这三条都会**改变对手的决策**：对手得考虑「我这招会不会被拆」
「我加盾会不会被你抢」，这才叫交互。

## 七、硬标准：响应式（2026-10-22 追加）

委托方二次批评：问题不在条数，在**触发机制 / 出发点**。

**自发式**（错）：时机是「我自己做了什么」，动作是「给我自己加数值」。
没有对手参与，不需要对手配合，也不会因对手怎么做而改变。

**响应式**（对）：时机是「**对手做了什么 / 正要做什么**」，动作是「干预他的结算」。

三档时机，按强度递增：

| 档 | 时机 | 干预点 | 例 |
| --- | --- | --- | --- |
| 事前 | `命中判定前` / `行动开始` / `资源消耗前` / `暴击判定前` | 改他的结算前提 | 折锋（其攻击 -12） |
| 事中 | `技能施放后` / `获得护盾后` / `添加状态后` / `命中后` | 改他的收益 | 截势（其 CD +2） |
| 事后 | `击杀后` / `受到伤害后` / `闪避后` | 追索 | 反手（还击 80%） |

**一条真意合格的最低线**：把它的时机关掉，对手的战斗会不会受影响？
不会 → 它是自发式，重写。

**判据**：池子里「监听对手」的条数应当**过半数**。
