# 流派变体表

> 委托方批评：6 条是自我设限，12 条只是换了个数值继续设限。
> 正确顺序是：先问「这个流派有几种打法」，条数由打法推导出来。
> 槽位 6 是**携带上限**，池子要能让玩家组出不同流派。

## 一、推导方法

对每个流派问三句：

1. 这套功法有几个**发力点**（比如守土：格挡、反伤、残血）？
2. 每个发力点能玩出几种**不同选择**（比如格挡流可以「叠减伤」也可以「格挡转护盾」）？
3. 每个选择写 1-2 条真意，池子自然就有了——**不预设总数**。

## 二、守土（人族）的推导

| 发力点 | 变体 | 真意 |
| --- | --- | --- |
| 格挡 | 叠减伤 | 承力、负壳 |
| 格挡 | 格挡转护盾 | 夺盾 |
| 格挡 | 格挡后还击 | 应手 |
| 反伤 | 反伤叠层 | 反壳 |
| 反伤 | 反伤转真伤 | 裂甲 |
| 残血 | 残血加格挡 | 残壁 |
| 残血 | 残血回血 | 固本 |
| 残血 | 濒死免死 | 死守 |
| 控制 | 被控解控 | 破缚 |
| 控制 | 被控反击 | 反手 |
| 拖后 | 每回合回血 | 养息 |
| 拖后 | 被打回精神 | 沉渊 |
| 节奏 | 推对手行动条 | 迟滞 |
| 节奏 | 自己推条 | 换命 |
| 削弱 | 削对手防御 | 瓦解 |

**推导结果：15 条。** 不是 6，不是 12，是 15——因为这个流派有 15 个可玩的选择点。

玩家从 15 条里带 6 条，能组出至少三种完全不同的守土：

- 纯格挡流：承力 + 负壳 + 夺盾 + 应手 + 残壁 + 养息
- 反伤流：反壳 + 裂甲 + 残壁 + 固本 + 反手 + 应手
- 拖后流：养息 + 沉渊 + 固本 + 死守 + 破缚 + 迟滞

## 三、抢攻（鲛人）的推导

| 发力点 | 变体 | 真意 |
| --- | --- | --- |
| 先手 | 推对手条 | 夺先、压浪 |
| 先手 | 推自己条 | 追浪 |
| 连击 | 命中加连击 | 夺浪 |
| 连击 | 连击加伤 | 叠浪 |
| 爆发 | 击杀推条 | 赌浪、断潮 |
| 爆发 | 破对手防 | 裂浪 |
| 反制 | 闪避还击 | 顺浪 |
| 反制 | 施放失败还击 | 换浪 |
| 打断 | 加对手 CD | 断浪 |
| 回浪 | 受击推条 | 回浪 |

**推导结果：约 12-14 条。**

## 四、我该改的习惯

| 坏习惯 | 改成 |
| --- | --- |
| 先定条数再填 | 先列变体，条数自然出来 |
| 六条覆盖六个「角色」 | 每个发力点展开成 2-4 条 |
| 填满就交差 | 问一句「玩家能组出几种不同打法」 |
