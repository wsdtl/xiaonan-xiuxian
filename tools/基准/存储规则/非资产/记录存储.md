# 非资产库（记录）的存储规则

适用：战报（`log_battle_reports`）、探索战斗记录（`exploration_*`）这类**记录**。
背景：记录库**周期性清理**，不背历史兼容；设计目标只有一条——**增删改查最快**。

1. **键＝记录编号**：一条记录一个键（如 `exploration_battle/<会话>:<序号>`、战报 `<编号>`），查改删都是 O(1)；
   **不许把物品、玩家、时间拼进键** ✗ —— 那会让人误以为它是物品身份（`01100002|用户编号` 就是这么来的）；
2. **记录体扁平**：谁、何时、什么东西、几个，各是**平级字段**；物品明细用 `{物品指称: 数量}` 或条目数组，
   **不再套一层自己拼的字符串键**；
3. **不存可重算的东西**：能从别处算出来的不落盘（记录薄，写才快）；
4. **清理靠时间字段**：每条带写入时间，清理按它批量删，**不做全表扫描**；
5. **物品指称只借资产规则的"写法"**（唯一形式），**不借"键就是指称"那一套**；
6. **读写路径上不碰资产库**：记录只读写自己；要发放就走资产库自己的口。
