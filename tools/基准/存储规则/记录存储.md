# 记录存储（非资产库）

适用：战报（`log_battle_reports`）、探索战斗记录（`exploration_*`）这类**记录**。
记录里的**物品指称写法**按同目录的 `id化存储.md`；**本文件只写记录库自己的规矩**。
背景：记录库**周期性清理**、不背历史兼容；设计目标只有一条——**增删改查最快**。

## 一、键

**一条记录一个键**（`exploration_battle/<会话>:<序号>`、战报 `<编号>`），查改删都是 O(1)；
**不许把物品、玩家、时间拼进键** ✗ —— 那会让人误以为它是物品身份。

## 二、记录体

1. **扁平**：谁、何时、什么东西、几个，各是**平级字段**；物品明细用 `{物品指称: 数量}` 或条目数组，**不再自己拼字符串键**；
2. **薄**：能从别处算出来的不落盘（记录薄，写才快）；
3. **存储形态**：整条 `zlib(6) → base64 → 前缀` 打包（`core/database/storage.py`），**按记录编号整块读写**——
   所以键要短、记录要薄，内部形状以整块读写最快为准。

## 三、清理与边界

1. **清理靠时间字段**：每条带写入时间，清理按它批量删，**不做全表扫描**；
2. **读写路径不碰资产库**：记录只读写自己；要发放就走资产库自己的口。
