## 二十九、瘦身与同类合并（2026-10-12 之后，本轮实测）

**做了什么**（每条都有闸门与回执双证；只写结果，过程在提交说明里）：

1. **中间文件**：删 `_输出/测试临时`（pytest 分片临时件，108 MB，每次跑闸门自动重建）、
   `__pycache__` 312 个目录（26 MB）、`log/`（25 MB）、`.pytest_cache`；`_输出/` 从 320 个历史探针
   收到四件仪器（说明 / 比回执 / 录回执基线 / 回执基线）。旧游戏库备份挪进 `.runtime/备份/`（没删）。
   **仓库 392 MB → 约 176 MB**（另有 database 61 MB 与 .venv 属资源，不计）。
2. **台账瘦身**：`tools/基准/说明.md` 从 408 KB / 5008 行收到 3.7 KB——31 个历史大节正文移出仓库
   （原文在 git 历史，`git show <提交>:tools/基准/说明.md` 可取回），只留索引与维护规矩。
   子目录 `tools/基准/归档/` 的尝试**被判据拦下**（检查历史遗留.py 明写 tools 下目录名不许带「归档」），已撤销。
3. **代码同类合并**（都是逐字相同的那一类，行为不变）：
   `_short_id` 三份 → `qq_protocol/ids.py`；`_plain` 四份 → `game/cmd/site.py::to_jsonable`；
   13 个 site.py 的响应头与 10 条重复 CSP → `PAGE_HEADERS` / `PAGE_CSP` / `PAGE_CSP_WITH_IMAGES`；
   `failure` 九份 → 一份；宗门洞天三处 `_buttons` → `project_dungeon_buttons`。
4. **按边界分家**：HTTP 契约（响应头、JSON 失败回执）从 `game/cmd/presentation.py` 搬到
   `game/cmd/site.py`——那个模块只管消息，任何 reply.py 都导入它，不该把 fastapi 拖进回复链。
