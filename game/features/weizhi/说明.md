# 位置查看玩法微服务

本服务组合世界、玩家位置、人物公开摘要、公开状态、队伍公开摘要、世界道侣和宗门**七个**核心服务（宗门同行状态由宗门核心给）。`位置`返回当前位置事实；裸命令`附近`返回周边概览；`附近 地点`只计算静态地点；`附近 修士`把当前地点的本地修士与坐标范围内的动态来往修士分栏分页。

回复文案、格式模板和按钮定义来自“位置展示”数据集。`presentation.py`在初始化时把**七份** JSON（展示/规则 3 份、展示/按钮 4 份）一次转换为稳定的 `PositionCopy`、地点功能按钮、页面按钮和距离方向配置，并拒绝缺失数据文件、无效占位符、未知页面、无效按钮条件或重复编号；`service.py`只组合位置与附近事实，命令层不直接读取 JSON。

附近查询不读取背包、完整属性、修行构筑或本命武器。敌人池不进入附近列表；处于 JSON 声明为不出现状态的玩家会被过滤。查询结果只用于展示，邀请、切磋、交易等未来行为仍须在提交时重新校验位置。
