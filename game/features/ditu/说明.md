# 公开地图玩法微服务

本服务只编排 `game.core.world` 已经建立的不可变地图快照，不读取 JSON 文件、不保存玩家位置，也不提供移动或地图交互。寻路属于同一世界核心的公开能力，但由独立的 `xinglu` 玩法调用，不进入地图展示服务。

- `snapshot()` 返回 Web 地图需要的完整只读快照。
- `overview()` 从同一快照派生世界名称、说明、地图尺寸以及区域、地点和道路数量，供“地图”命令使用。

`game/cmd/通用/地图` 只处理命令消息和 HTTP 序列化；地图事实始终由世界核心服务解释。行路、探险或玩家位置展示分别进入对应玩法，不扩充本服务的职责。
