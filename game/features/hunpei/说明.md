# hunpei（婚配）玩法微服务

## 定位

**婚配**的玩法微服务：管**生育**这一条独立的路（不是培养、也不是结契）。

设计见 _输出/血脉系统-DNA一条线.md 与 _输出/血脉匹配方案.md。

## 三层要分清

| 层 | 内容 | 谁管 |
|---|---|---|
| 道侣培养 | 结交 / 送礼 / 好感 / 回礼 | 既有系统，不动 |
| 婚配（结契） | 同行道侣 | 既有 邀约 / 暂别，不动 |
| **生育** | **本组件** | 满足条件后主动生育 |

**生育不是「培养了就能生」**：要同时满足条件才触发。

## 职责（第一版）

| 命令 | 作用 |
|---|---|
| 生育 | 与当前同行道侣生育，生成新生儿并入族谱 |

## 生育的条件（第一版）

1. 当前有同行道侣（邀约的成果）
2. 邀约时双方异性（事实记下来，不随后续变性改写）
3. 生育那一刻双方仍是异性
4. 双方都活着
5. 有生育丹
6. 未超每代胎数上限（**每代 10 胎**）

## 节奏纪律

- **无冷却**：数据里不出现「冷却 / 间隔」字段
- 只有两个闸：**每代胎数上限** + **生育丹**
- 传承前后为一代：一次「传位」即代次加一，胎次随之清零
