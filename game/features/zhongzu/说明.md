# 种族图鉴玩法微服务

本服务只编排 `game.core.character` 已经查死的种族登记表（`角色/规则/种族/种族.json`），
不读 JSON 文件、不算数值、不判断资格。种族的**结构**在角色核心启动期就查死了：
名字不许重名、编号不许重复；这里只把它们按族系分组、按编号排序，供命令侧展示。

- `overview()` 返回全部种族按族系分组的只读结果，附带总数与档次次序。
- `find(键)` 同时接受**编号**与**名字**：编号是稳定标识（`编号.json` 写明「编号可修改：false、
  名称可修改：true」），名字是给玩家看的。

`game/cmd/通用/种族` 只处理命令消息、分页与文案；种族事实始终由角色核心解释。
