# 查看角色玩法微服务

本服务组合角色核心、玩家状态、玩家位置、世界地点、伤势、先天灵宝与托管**七个**公共微服务，向触发层返回一个人物总览。角色资产仍由 `game/core/character` 独占解释，地表 `xy` 由 `game/core/location` 独占解释；本服务不读取数据库状态字典，也不自行解析 JSON。

人物总览包含身份、境界、等级、经验、灵石、战斗属性、当前资源、修行槽、本命武器、背包摘要、地表位置、行为/队伍/控制三类状态，以及**长期伤势**与**当前执掌的先天灵宝**（托管中的人物把状态名改成「已暂停」）。详细背包、修行装配和状态转换由各自后续玩法负责。

总览还带上 `attribute_baselines`——每个属性的基准值，取自角色核心（属性定义里的 `默认值`）。展示层靠它判断「这条属性有没有信息」：等于基准的加成类属性（基准 100）不值得占玩家的屏幕，触发层因此不会把一屏的「100」印出来。
