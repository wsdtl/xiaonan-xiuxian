# 查看玩法微服务

本服务只编排 `game.core.item_catalog` 的只读编号实体查询结果，不访问数据库、不读取 JSON 文件、不发送消息。

命令层负责把查询结果渲染成玩家消息；玩家只需输入任意正式编号或完整名称。名称重复时返回带类别的唯一编号候选，由玩家继续精确查看，不要求输入实体类别。

## 品级

品级是**实例级**事实（`data/基础/定义/编号.json` 明写编号不承载品级），实体本身没有品级。
`inspect(query, user_id)` 因此多取一份：走 `asset.snapshot` 查执行者持有该编号的品级，放进
`held_grades` 交给命令层显示。没创建人物、没持有，都按「未持有（按基础值）」处理，不假装知道。
构筑四类的品级还要带上它的能力倍率；**卡面正文的逐个数字不随品级改写**。
