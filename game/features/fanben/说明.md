# 返本玩法微服务

## 功能

### 一、启动期读取

1. **规则不在本包**：初始化用世界服务取「返本」功能配置，只取 `丹药`、`目标种族` 与 `状态守卫` 三个字段；功能名「返本」写死，多一个少一个声明都报错。
2. **与易形同处一地**：太素坊的两仪泉管「重塑形体」，「易形」管性别、「返本」管种族，两者共用一处地点、各自一个功能。

### 二、请求前置校验

3. **幂等排在最前**：先按玩家与请求编号查已提交事务，已提交且业务类型是「返本还元」就回放，业务类型不符按冲突拒绝。
4. **状态守卫**：用 `状态守卫` 授权，不通过即拒，理由取守卫给出的原文。
5. **地点门槛**：先取当前位置坐标、由世界服务还原地点，`可用功能` 不含「返本」就拒绝。

### 三、交割

6. **目标恒为玩家自身**：请求只收玩家与请求编号；目标种族来自地点配置，人物已经是该族即拒。
7. **只消耗最低品级**：按 `丹药` 编号取纳戒全部堆叠，无堆叠即拒；有堆叠则按品级次序取最低一堆扣 1。
8. **同事务提交**：纳戒扣减与人物变更合成一笔业务类型「返本还元」的事务，载荷只记人物名称、原种族、新种族与丹药名称。
9. **只改种族一个字段**：天生规则、卡池来源、成长修正与寿元系数都按种族现算，改完自动跟着换；寿元上限随新种族重算，年龄不越界；已经长出来的属性不回溯。

### 四、命令入口

10. **`返本`（别名 `太素坊返本`）**：在太素坊把人物种族转为地点配置指定的那一族；走状态守卫，业务类型「返本还元」。本包没有按钮，命令即全部入口。
