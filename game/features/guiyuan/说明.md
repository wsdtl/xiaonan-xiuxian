# 归元玩法

提供归元观专属玩法：消耗一颗万法归元丹，重置当前同行道侣某一类构筑（功法、真意或气机）的装配，用于重抽方向。

## 流程

1. `归元` 预览展示道侣名称、所在地点与现有构筑数量，并提示是否持有丹药；
2. 提交时校验状态守卫、当前位置具备「归元」功能、类别只能是功法、真意或气机；
3. 在同一笔 `万法归元` 事务中扣除最低品级的万法归元丹并写回道侣构筑。

请求编号幂等：重复提交同一请求返回首次结果，类别不一致时报冲突。

## 边界

本玩法不解释道侣构筑规则，重抽计划由 `companion` 给出；不自行扣减库存。器律不在可重置范围内。文本与图标全部来自 `data/玩法/归元/展示`。
