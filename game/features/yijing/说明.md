# 意境特性包

## 功能

### 一、本包范围

1. **只做薄薄一层**：取视图、调人物核心的意境计划、落一笔事务；判断与校验都在人物核心里。
2. **三个入口**：`inspect`（看）、`choose`（选路）、`upgrade`（花道行升一阶）。
3. **道行来自境界突破到头**，发放在人物核心里，本包只负责花。

### 二、口径

4. **取值只走核心的两个公开口**：阶价 `yijing_cost`、阶上限 `yijing_cap`，本包不另存价表。
5. **改路把已练的阶清零**（锁认路），这件事由人物核心的 `plan_yijing_choose` 做。
6. **落库一笔事务**：业务类型「意境选路」或「意境升阶」，载荷只记意境编号。
7. **幂等排在最前**（接收时补）：两个入口都先按玩家与请求编号查已提交事务，命中就**不再算计划**、直接回看现状——
   状态已经改过，再算会得到另一份计划（升阶甚至会撞上境界上限直接报错）；编号用于别的业务时按冲突拒绝。
8. **阶 0 是合法状态**（接收时修）：选路把已练的阶清零，此时「有编号、阶为 0」= 选了但还没花道行激活；
   人物状态校验原先写的是「有编号时阶必须 1..9」，于是选路会当场写出一个自己校验不过的状态、
   下一次读人物就抛错——这条线原先一个测试都没有，所以谁也没发现。现在由 `tests/test_yijing.py` 守着。
