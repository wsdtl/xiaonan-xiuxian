# 使用网关

## 功能

1. **只做路由**：按物品编号前缀查物品组件里的使用规则，把「执行 / 重定向 / 暂缓 / 不可使用」翻译成统一结果；不拥有任何领域结算。
2. **端口注入**：各 feature 的 use 端口由组合根注入，使用网关不 import 具体玩法服务。
3. **位置与目标**：端口返回候选（槽位、孔位、人物/道侣），网关校验候选后再执行；位置不合法时拒绝。
4. **文案在数据**：错误标题、缺品级提示与重定向帮助全部来自使用规则数据集，不写死在代码里。

## 数据集

| 数据集 | 路径 |
| --- | --- |
| 使用规则 | 物品/规则/使用.json |
