# 讨伐玩法

编排讨伐玩法：在当前地点发起首领讨伐、查看进度、领取结算。

## 职责

从 `action_group` 取得当前有序参与者与领队身份，调用 `raid` 核心发起、查询或结算讨伐，并把进度、战果与奖励渲染为回复。参与者的讨伐状态、战斗编排与奖励发放全部由核心服务完成。

## 边界

本组件不判断领队资格、不决定奖励内容——非领队发起时由 `action_group` 返回明确结果，本组件只把结果翻译成提示。它只依赖 `data` 读取 `讨伐展示` 文本，不读取讨伐或战斗 JSON，也不直接访问数据库。

展示文本在 `initialize()` 中一次性读取并冻结为只读映射；组件不提供任何写接口。
