# 网页公开玩法微服务

## 功能

### 一、本包范围

1. **一条全局开关**：管住所有「网页直接读你的数据」的页面；页面不各造一个开关。
2. **两个入口**：打开与关闭，各管一头，收的是明确的目标状态，不是取反。
3. **一份清单**：列出已经打开的人，网页据此显示「挑自己」；没人打开就是空清单。

### 二、口径

4. **开关存在共享索引里**，每人一行；理由是网页必须能**枚举**谁打开了，而人物状态枚举不出来。
5. **可见性**：打开了才看得见，没人打开就什么都看不到；装配台自己的全池也是「所有已打开的人」。
6. **幂等排在最前**：同一条请求重放直接回放，业务编号用于别的操作按冲突拒绝。
7. **已经是目标状态就不再写一笔**：重复打开或重复关闭不落事务。
8. **没人物开不了**：开关挂在玩家身上，尚未创建人物时按错误拒绝。

### 三、与页面的关系

9. **页面只读**：本包不给页面任何写入口，页面只拿清单与开关状态。
10. **页面不许露出开关以外的数据**：清单只给编号与名字。

## 数据集

| 数据集 | 本包路径 |
| --- | --- |
| 网页公开展示 | `data/玩法/网页公开/展示/文本.json` |

命令组是两条全匹配命令（网页资源公开 / 网页资源关闭），各管一头、不玩取反开关；守卫是「已创建」——开关挂在人物身上。
