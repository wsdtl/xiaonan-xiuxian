# 洗根玩法微服务

## 功能

### 一、启动期读取

1. **规则不在本包**：初始化用世界服务取「洗根」功能配置，只取 `丹药` 与 `状态守卫` 两个字段；功能名「洗根」写死；丹名从 `丹药.<编号>.名称` 读出，不硬编码。
2. **与归元观同处一地**：归元观第一个功能「归元」重做同行道侣的构筑，本功能重掷玩家自己的五行根性，两者共用一处地点。

### 二、请求前置校验

3. **幂等排在最前**：先按玩家与请求编号查已提交事务，已提交且业务类型是「灵根重铸」就回放，业务类型不符按冲突拒绝。
4. **状态守卫**：用 `状态守卫` 授权，不通过即拒，理由取守卫给出的原文。
5. **地点门槛**：先取当前位置坐标、由世界服务还原地点，`可用功能` 不含「洗根」就拒绝。

### 三、交割

6. **目标恒为玩家自身**：请求只收玩家与请求编号；产出必须完整含木火土金水、每项 0 到 100、合计 100（由生成规则本身保证，入库校验也再查一遍）。
7. **掷到换个样子为止**：与原来完全相同就继续掷，上限五十次；重掷了几次记进载荷，重放因此也算得出来。
8. **只消耗最低品级**：按 `丹药` 编号取纳戒全部堆叠，无堆叠即拒；有堆叠则按品级次序取最低一堆扣 1。
9. **同事务提交**：纳戒扣减与人物变更合成一笔业务类型「灵根重铸」的事务，载荷只记人物名称、原根性、新根性、重掷次数与丹药名称。
10. **随机但不飘**：种子由「玩家 + 请求编号」决定，同一条请求重放掷出同一副；换一条请求才是新的一掷。

### 四、命令入口

11. **`洗根`（别名 `归元观洗根`）**：在归元观重掷自己的五行根性；走状态守卫，业务类型「灵根重铸」。本包没有按钮，命令即全部入口。
