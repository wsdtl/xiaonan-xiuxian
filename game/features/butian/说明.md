# 补天玩法

提供 `补天` 命令：在裂天原消耗一颗「同境界单属性突破丹」，为人物或同行道侣补正已经完成的那次突破属性，再消耗一颗九霄补天丹作为代价。

## 流程

1. 校验状态守卫、当前位置具备「补天」功能、目标只能是人物或道侣；
2. 用来源突破丹请求 `character` 或 `companion` 生成补正计划，并核对当前可补正的突破节点与请求境界一致；
3. 在同一笔 `九霄补天` 事务中扣除最低品级的九霄补天丹并写入补正后的永久属性。

请求编号幂等：重复提交同一请求返回首次结果，请求内容不一致时报冲突。

## 边界

本玩法不解释突破规则与属性数值，补正计划由角色或道侣核心给出；不自行扣减库存，资产变更经 `asset` 计划后在事务中提交。文本与图标全部来自 `data/玩法/补天/展示`。
