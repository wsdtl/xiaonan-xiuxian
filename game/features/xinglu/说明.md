# 行路玩法微服务

本服务编排一次即时行路，但**行路是整组行动**：先向行动编排核心取参与者，逐人过「自主空闲且可行动」守卫，任何人处于宗门洞天都直接拒绝（要先出山门），再向位置核心读取当前 `xy`、向角色核心批量取境界、调用世界核心规划路线，最后由位置核心**一次迁移整组**。

- 目的地只接受完整地点名或两个整数构成的 `xy`。
- 行程立即抵达，不创建“行路中”状态，不保存路线或剩余时间。
- 路线、地形、道路、海拔、折算指标和二十境界叙事全部由世界核心依据正式 JSON 返回。
- 人物位置只由位置核心写入；本服务没有数据库写权。
- 位置在规划与提交之间发生变化时，本次行路失败，不覆盖新的位置。

触发层只负责接收 `去 地点名` 或 `去 x y` 并展示本服务结果。
