# 赠送玩法

编排 `赠送` 命令：把纳戒中的物品或灵石赠予其他玩家。**不要求同处一地**——`玩家赠送` 的 `双方必须同地` 是 false，按名字或用户编号可以跨地点送达（命令帮助里也这么写）。

## 职责

把目标名或编号解析为稳定用户编号，校验物品或灵石存在与数量，再调用 `gift` 核心完成转移。物品名称与公开定义来自 `item_catalog`，接收者名称来自 `character`。

可送的两类：灵石（`货币`）与 `基础物品` 类别；`单次数量上限` 是 1 亿。（`data/玩法/交易/规则/玩家赠送.json`）

## 边界

本组件不解释物品效果、不判断好感、不写库存——转移由 `game/core/gift` 在单笔事务中完成。它依赖 `data` 读取 `赠送展示` 文本与 `赠送按钮`，不读取物品 JSON，也不直接访问数据库。道侣专属的赠予分支由 `game/features/daolv_jiejiao` 负责。
