# 战报日志（zhanbao.battle_log）

**管什么**：非资产库（`database/runtime_log.db`）里 `log_battle_reports` 这一张表的读写——
按战报编号整条读写（`save`／`load`／`peek`／`recent`／`cleanup`），本体按 **zlib 9 级**打包后落盘。

**为什么在这里**：二级命令组件「通用/战报」所用的微服务就是 `game/features/zhanbao`（按组件拼音命名）；
非资产库的存取归核心侧解析（`runtime_log_database_path`），这里只放战报自己的读写实现。

## 边界

- 战报玩法微服务经本包读战报：日志是观测数据，**不是游戏规则、不是玩家资产、也不是战斗事实**；
  维护者入口（天道后台）只读消息流水，不读战报。
- **协议 `BattleReportSink` 与路径 `runtime_log_database_path` 的归属见下一轮归位** ✗：
  `game/core/duel`、`game/core/sect_war`、`game/core/database/storage.py` 也 import 它们，
  核心不能依赖 features，故这两样要提到核心侧模块，features 反过来从核心 import。
