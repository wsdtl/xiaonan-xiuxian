# 战报页面玩法

按**战报编号**供应分享页要的数据：从**非资产库**里的战报现算展示包，再按页面拼的五条路径
切片（战报头、片段、事件、参战者、行动前后状态）。

## 职责

- `payload(编号)` 取非资产库里的战报并算成展示包；算好的按编号在内存里留最近几份——页面
  打开会连着要五份数据。
- 五个切片口（`main` / `segment` / `events` / `participants` / `transition`）只做搬运：
  切出来的每一份与一次算完整的展示包对应部分逐项相同（判据在单元测试里）。

## 边界

展示包**不进任何库**：它比战报还大，而每一步都能从战报算出来。本组件不跑战斗、不结算、
不发奖励，也不改任何存档。

战报是**非资产数据**：按编号存在非资产库里，与谁发起、存在谁名下无关，所以分享地址只需要
编号；**过期与不存在分开说话**——过期说「这份战报已经过期」，不存在才回空、由命令组件对外
说 404。它只依赖战斗核心（算展示包）与非资产仓储的读契约（`load` / `peek`），不读 JSON、
不直接访问数据库。
