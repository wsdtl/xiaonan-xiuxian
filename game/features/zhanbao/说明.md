# 战报页面玩法

按战报编号供应分享页要的数据：从**存档战报**现算展示包，再按页面拼的五条路径切片
（战报头、片段、事件、参战者、行动前后状态）。

## 职责

- `payload(编号)` 取存档战报（宗门战记录里的那份）并算成展示包；算好的按编号在内存里
  留最近几份——页面打开会连着要五份数据。
- 五个切片口（`main` / `segment` / `events` / `participants` / `transition`）只做搬运：
  切出来的每一份与一次算完整的展示包对应部分逐项相同（判据在单元测试里）。

## 边界

展示包**不进存档**：它比战报还大，而每一步都能从战报算出来。本组件不跑战斗、不结算、
不发奖励，也不改任何存档；编号对不上就回空，由命令组件对外说 404。
它只依赖战斗核心（算展示包）与宗门战核心（取存档），不读 JSON、不直接访问数据库。
