# 启动契约

`game/startup` 只保存跨命令、跨核心服务和全量 JSON 组合后必须成立的启动契约。所有检查在服务装配完成、正式接收请求前执行；任一失败都会终止启动。

检查的具体实现只能放在 `contracts.py`，`__init__.py` 只导出公共入口。`game/app.py` 完成全部服务装配后只调用一次 `validate_startup_contracts()`，不得在各个服务或命令中散落同类启动检查。

## 构筑模板装载

功法、真意、气机和器律是四个不同的构筑方向。功法、真意和器律的存储正文可以引用战斗构筑模板；数据服务在建立正式快照时展开引用，后续契约校验和战斗执行消费展开后的完整能力树。气机直接保存固定属性能力。

- 模板只负责保存和复用效果结构及参数，不拥有功法、真意、器律的玩家显示名称，不创造原子能力之外的新语义；
- 构筑实体和模板引用必须符合当前字段契约，模板缺失、参数不完整或引用循环均属于数据错误；
- 玩家可见名称由构筑实体提供，不由底层能力名或模板编号拼接。

四个方向共用的只有 `编号 + 名称 + 说明 + 属性构成` 这层身份，其余形状各归各的：

| 方向 | 编号前缀 | 根能力 | 特点 |
| --- | --- | --- | --- |
| 功法 | `40` | 主动技能（至少一项）、被动技能 | 承载完整战斗循环 |
| 真意 | `41` | 只有被动技能，恰好一项 | 只承载被动规律 |
| 气机 | `42` | 只有固定属性加成，恰好一项 | 不引用事件、不监听、不生成技能 |
| 器律 | `70` | 只有被动技能，恰好一项，另有器阶、铸法、兽引 | 锻在本命武器孔位上 |

形状契约在 `data/战斗/规则/构筑契约.json` 声明，由 `game/core/combat/builds.py` 执行；`CombatService.initialize()` 在装配战斗核心时逐类校验，越界即终止启动。跨方向借用字段（真意长出主动技能、气机长出监听、器律丢掉器阶）都属于启动错误。

## 原子能力是唯一词汇表

战斗核心只认 `战斗/定义/原子能力.json` 登记的原子能力：能力名决定执行器，字段规约决定该节点允许写哪些字段。构筑不再有第二套中间语言，因此**新增设计只需写 JSON**：

- 复用已有原子能力时，按它的字段规约写节点；
- 需要新语义时，先在 `原子能力.json` 登记能力与执行器，再在卡片里使用；
- 执行器名对应代码入口，不能凭数据自由创造。

通用执行能力不拥有具体构筑内容：伤害标签、事件文案和状态名称都属于卡片自己。

## 能力与构筑边界

构筑之间允许通过真实战斗事件产生联动，例如"敌方暴击后触发本构筑被动"；不允许一个构筑读取、修改或结算另一个构筑的状态、计量或裁定。

一个构筑写入的每项计量必须能在同一构筑内找到对应裁定，除非该计量明确标记为只记录、不结算的事实。该闭环规则属于维护审查项目（`tools/架构审查/检查构筑形状.py`），在接入前不得把它描述为已完成的启动检查。

## 运行时作用域

战斗装配时，每个 `CombatBuildRef` 都会得到唯一的 `实例`。实例是一次装配的作用域，不是内容编号，也不是玩家属性；同一个内容重复装配时必须使用不同实例。

- 技能和被动记录实例归属，事件监听按"参战者 + 实例 + 监听键"去重。
- 构筑计量按"参战者 + 实例 + 计量名"存取；同名计量只在同一实例内可读写。
- 状态保留来源实例；叠加、转移、复制和移除不得跨实例匹配，除非节点明确声明允许跨实例。
- 通用执行器只接收并传递实例上下文，不生成或改写构筑名称。
- 事务快照必须完整保存和恢复实例作用域，回滚后不得遗留计量、监听或状态。

战斗核心已有的公共触发次数、行动条、技能冷却等属于战斗公共状态，继续使用各自的公共键，不套用构筑实例作用域。

## 启动校核范围

启动阶段当前只校核会阻断运行的契约：

1. 数据服务先完成全量 JSON 解析和实体索引构建。
2. 战斗定义、战斗规则和阵法节点契约可以解析；原子能力与能力树符合字段契约。
3. 功法、真意、气机、器律各自通过自己的形状契约（编号前缀、字段集合、根能力、能力数量、权重唯一）。
4. 命令编号、数据库状态归属和守卫引用没有冲突。

卡片 `说明` 的特异性、计量产生与裁定的完整闭环属于内容审查，由 `tools/架构审查/` 负责，启动阶段不重复执行内容审查。

错误信息必须包含冲突双方的构筑、编号、文件和字段路径，便于直接修正 JSON。

单个微服务自己的运行数据校验仍归该微服务所有。维护性审查可以调用启动契约的正式检查函数，但不得复制规则；不影响启动正确性的风格、目录和命名审查仍属于维护工具。
