# 藏经阁核心

藏经阁核心解释 `data/宗门/规则` 中的藏经阁条目与借阅规则，负责把功法、真意与气机作为宗门藏书提供给成员借阅。

## 数据与依赖

- 数据集：`宗门规则`；
- 状态类型：无；
- 依赖：`data`、`database`、`sect`、`asset`、`growth`。

## 职责

维护藏书目录与借阅记录，把借出的内容登记为人物资产。启动期校验藏书条目与功法明细的形状；借阅时判成员身份、槽位与构筑冲突（`growth`），库存写入统一交给 `asset`。**当前没有职衔或贡献门槛**——规则数据里也没有门槛字段。

## 边界

本服务不解释功法、真意与气机的战斗能力——那是 `game/core/combat` 的装载职责；也不计算贡献等级，因此不依赖 `game/core/sect_progress`。借阅产生的资产变更不得绕过 `asset`。
