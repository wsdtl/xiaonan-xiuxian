# 藏经阁核心

藏经阁核心解释 `data/宗门/规则` 中的藏经阁条目与借阅规则，负责把功法、真意与气机作为宗门藏书提供给成员借阅。

## 数据与依赖

- 数据集：`宗门规则`；
- 状态类型：无；
- 依赖：`data`、`database`、`sect`、`asset`、`growth`。

## 职责

维护藏书目录与借阅记录，校验成员职衔与贡献是否满足借阅门槛，把借出的内容登记为人物资产。等级门槛来自 `growth`，成员身份来自 `sect`，库存写入统一交给 `asset`。

## 边界

本服务不解释功法、真意与气机的战斗能力——那是 `game/core/combat` 的装载职责；也不计算贡献等级，门槛判定调用 `game/core/sect_progress` 的公开结果。借阅产生的资产变更不得绕过 `asset`。
