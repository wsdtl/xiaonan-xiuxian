# 成长核心微服务

本服务只解释人物与道侣共用的修士等级经验曲线、境界上限与构筑相冲。它不保存任何玩家状态，也不提交数据库事务。

本命武器经验、攻击、器阶、器律孔和器律适配全部由 `game/core/forging` 解释，成长核心不得读取炼器规则。

人物状态仍由 `game.core.character` 拥有，道侣实例仍由 `game.core.companion` 拥有。探险、闭关、人物培养和道侣培养取得本服务的纯计算结果后，由对应状态所有者生成 `StateMutation`，最后交给数据库微服务原子提交。

道侣功法、真意和气机只在首次邀约时从实体声明的三个个人池生成一次并保存；普通升级、查看、重启和再次邀约都不会重新随机。唯一的重抽入口是道侣「归元」：它按类重抽功法、真意或气机**其中的一类**（`redraw_companion_category`），其余两类不动。器律不进入随机构筑，由本命武器升级开放空孔后手动覆炼。
