# 讨伐核心微服务

讨伐服务只读取 `世界/内容/<区域>/<地点>/` 下的讨伐定义和四类独立来源：首领、辅助、属从、奖励。它负责按讨伐规则生成敌方成员，再把这些成员转换为战斗核心统一的 `CombatGroupSpec` 请求；编组契约属于所有战斗模式共用的战斗核心，不属于讨伐。

- 每场战斗的我方和敌方都可以提交多个编组；讨伐规则只规定本玩法的敌方编组构成。
- 讨伐首领编组始终只有一个；我方只有一个编组时不生成属从编组。
- 首领、辅助和属从使用不同的实体类别和资源池，不能回退到普通敌方池。
- 辅助成员归属于首领编组，编组身份为 `辅助`；首领成员是该组主战者。
- 属从的等级和属性由属从实体定义，讨伐定义只保存人数范围和池引用。
- 普通攻击和群体效果仍由战斗核心规则执行；本编组辅助目标通过战斗目标范围 `本编组主战者` 解析。
