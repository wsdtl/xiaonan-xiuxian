# 宗门核心

宗门核心解释 `data/宗门/规则`，独占 `sect_invite` 状态，是宗门主体、成员、邀请与入口等级的唯一读写者。

## 数据与状态

- 数据集：`宗门规则`；
- 状态类型：`sect_invite`（待处理邀请）；
- 依赖：`data`、`database`、`player_state`。

## 职责

维护宗门的创建、解散、宗主转让，成员的加入、退出与逐出，以及邀请的发出、接受与拒绝。成员关系与玩家状态槽位在同一笔事务中提交，玩家是否处于可邀请状态由 `player_state` 判定。

## 边界

本服务不解释宗门设施、灵藏、藏经阁或宗门战的业务规则，这些分别归 `game/core/sect_facilities`、`sect_assets`、`sect_library` 与 `sect_war`。本服务也不发放贡献等级——贡献由 `game/core/sect_progress` 解释。所有宗门类玩法必须调用本服务，不得自行拼装成员关系。
