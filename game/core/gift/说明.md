# 赠送核心

赠送核心解释 `data/交易/规则` 中的赠送参数，独占 `gift_result` 状态，负责把一件纳戒物品从赠出者转移到接收者。

## 数据与状态

- 数据集：`交易规则`；
- 状态类型：`gift_result`（不可变赠送事实）；
- 依赖：`data`、`database`、`location`、`character`、`asset`、`item_catalog`。

## 职责

校验双方同处一地、物品存在且数量足够，随后在同一笔事务中扣减赠出者库存、增加接收者库存并写入赠送事实。物品名称与公开定义由 `item_catalog` 解释，资产变更由 `asset` 执行。

## 边界

本服务不解释物品效果、不判断赠礼好感，也不处理道侣专属的赠予分支——道侣赠礼由 `game/features/daolv_jiejiao` 编排并复用本服务的转移能力。本服务不得绕过 `asset` 直接改写库存状态。
