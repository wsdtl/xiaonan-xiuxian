# 丹药核心

丹药核心解释 `data/服丹/规则` 与 `data/炼丹/内容/丹药`，把正式丹药定义翻译成可执行的恢复、战斗与特殊效果。它不拥有数据库状态，也不写玩家资产。

## 数据

- 数据集：`服丹规则`，同时消费 `炼丹` 组件的丹药实体；
- 依赖：`data`、`asset`；
- 状态类型：无（只读解释与计划生成）。

## 职责

按编号与品级解析丹药的恢复量、战斗增益或特殊效果，产出可直接提交给资产服务的消耗计划，以及交给战斗核心的战前丹药装配。恢复丹、战丹、突破丹和特殊丹四类由同一入口区分，调用方不解释丹药字段。

## 边界

本服务不扣除库存、不执行回血、不写战斗结果。服丹、补天、归元、易形与铜雀台等玩法只管提交请求并保存自己的结果状态；实际扣减由 `asset` 在同一事务中完成。
