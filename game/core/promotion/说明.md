# 升阶核心微服务

管基础物品的品级升阶：规则、报价与材料缺口方案。只出计划，不写数据库。

- 只允许灵植、灵矿、兽宝；灵石本身不能升阶，丹药/器律/阵法/构筑不在白名单。
- 每件消耗 1 枚目标品级灵石（按 `品级.灵石面值` 折黄品当量）；允许从任意低品直接跳到目标品级。
- 目标品级不能超过 `升阶.json.目标品级上限`；一次数量不能超过 `批量上限`。
- 启动时校验全库：任何来源→目标组合的灵石成本都必须不低于物品价值增量，防止套利。
- `plan_upgrade` 返回单品计划（物品增减 + 灵石找零，一笔库存变更）；`plan_requirements` 按炼制材料缺口给出逐条升阶建议，只读。
- 阵法继续读 `品级.灵石当量`（材料权重）；货币读 `品级.灵石面值`，两张表分开。
