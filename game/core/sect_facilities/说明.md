# 宗门洞天设施核心

宗门洞天设施核心解释 `data/宗门/规则` 中的设施、权限与炼制规则，是宗门洞天内三座生产设施的统一入口。

## 数据与依赖

- 数据集：`宗门规则`；
- 状态类型：无；
- 依赖：`data`、`database`、`sect`、`sect_assets`、`asset`、`alchemy`、`forging`、`formation`、`location`、`sect_progress`。

## 职责

按宗门职衔判定设施操作权限，组织炼丹、炼器与阵法加工三类设施流程，并把材料消耗、产成品入库和贡献结算收进同一笔事务。具体配方解释分别交给 `game/core/alchemy`、`game/core/forging` 与 `game/core/formation`，本服务只做权限、编排与事务。

## 边界

本服务不解释丹药、器律或阵法的数值规则，也不决定贡献等级门槛的计算方式——后者归 `game/core/sect_progress`。设施必须在宗门洞天空间内使用，位置事实由 `location` 提供，本服务不自行判断空间归属。
