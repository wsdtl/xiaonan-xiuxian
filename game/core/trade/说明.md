# 地点交易核心

地点交易核心解释 `data/玩法/交易/规则` 与地点商店内容，负责按地点与类别查询商品、计算成交价并完成买卖。

## 数据与依赖

- 数据集：`交易规则`；
- 状态类型：无（买卖通过资产服务落库）；
- 依赖：`data`、`database`、`world`、`location`、`character`、`asset`。

## 职责

按地点取得可用商店与商品列表，按品级价格系数计算单价，校验灵石余额与背包容量后执行买入或卖出。地点商店归属由 `world` 提供，玩家位置由 `location` 提供，资产变更统一交给 `asset`。

## 边界

本服务不实现供需浮动、税率或玩家间交易——`参考价` 只是静态估值锚，成交价不得被评分或随机逻辑隐式使用。本服务也不得直接改写背包状态或绕过 `asset` 扣减灵石。
