# 地点交易核心

地点交易核心解释 `data/玩法/交易/规则` 与地点商店内容，负责按地点与类别查询商品、计算成交价并完成**买入**（当前没有卖出入口）。

## 数据与依赖

- 数据集：`交易规则`；
- 状态类型：无（买卖通过资产服务落库）；
- 依赖：`data`、`database`、`world`、`location`、`character`、`asset`。

## 职责

按地点取得可用商店与商品列表，按品级价格系数计算单价，校验灵石余额后执行买入（本核心只有买入入口，没有卖出）。地点商店归属由 `world` 提供，玩家位置由 `location` 提供；**灵石扣减走人物核心、商品进修行资粮储备走资产核心**，两条变更同一笔事务提交。

## 边界

本服务不实现供需浮动、税率或玩家间交易——`参考价` 只是静态估值锚，成交价不得被评分或随机逻辑隐式使用。本服务也不得直接改写背包状态：灵石由人物核心计划扣减，商品由资产核心写入修行资粮储备。
