# 先天灵宝核心

本服务解释正式先天灵宝实体、玩家永久灵宝谱和唯一执掌槽。状态类型固定为 `innate_treasure`，不进入纳戒，也不允许道侣、交易、宗门仓储或掉落服务写入。

角色面板把执掌槽显示为独立的 `先天灵宝 0/1` 或 `1/1` 构筑槽；槽位数量只来自 `data/先天灵宝/规则/先天灵宝.json`，当前执掌编号只保存在本服务的 `innate_treasure/main` 状态，不复制到人物 `cultivation/main`。

其他业务只按公开的规则节点查询当前灵宝效果。持续玩法必须在开始时保存灵宝编号，结算时按快照解释；瞬时玩法可以读取当前执掌。服务不实现秘境掉落，后续秘境只能通过 `plan_acquire()` 把取得结果纳入自己的原子结算。

激活结果的结算载荷由本服务给出：`activation_payload()` 从包顶层导出（见 `presentation.py`）。原先炼丹、炼器、阵法、采集、闭关、服丹六个服务各抄一份逐字节相同的投影——载荷形状属于定义这个类型的包，`InnateTreasureActivation` 的字段一变，六处不会各自漂移。
