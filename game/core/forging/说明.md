# 炼器核心边界

本核心是 `本命武器.json`、`器则.json`、`铸法.json`、`归引.json`、`归脉.json`、器律和炼器工匠的唯一代码解释入口。

它负责本命武器经验、器阶、攻击和器律孔规则，也负责按当前位置工匠审材，将兽宝与灵矿一次性炼成一份器律。材料扣除与器藏增加在同一个数据库事务中提交；材料组合不完整时不产生任何变更。

**先天灵宝可以在「炼器成功」这一步介入**：能力为「返还灵矿」时，按 `比例`（向上取整）与 `最低数量` 里的较大者追回灵矿，上限是本次投入的灵矿总量；追回顺序是数量从多到少、同量先高品阶。这次激活会写进结果，由回复展示。

人物、道侣和敌人只能调用本包公开契约取得武器结果，不得再次读取或解释炼器 JSON。人物覆炼与道侣覆炼仍由各自培养组件修改对应本命武器，待覆炼器律统一存入玩家器藏。
