# 采集核心微服务

本目录只负责采药、采矿共用的活动事实：有序参与用户、当前位置与地形资源池快照、六轮预计算结果、按整轮解封、领队权限和原子结算。

`GatheringService` 通过稳定公共契约接收玩法名称和有序参与用户。它不解析 QQ 命令，不管理队伍或宗门成员，不生成展示文本，也不解释灵植药脉、灵矿铸脉、炼药、炼器或阵法用途。

采药和采矿分别读取 `采药/规则/采药.json` 与 `采矿/规则/采矿.json`。具体物品从世界核心返回的当前地形池抽取，品级由资产核心统一生成，最终物品和玩家行为状态在同一数据库事务中结算。道侣以“相助”方式增加所属玩家的采集单位，不拥有独立纳戒和结算页。
