# 闭关核心

闭关核心拥有闭关会话、最近闭关和闭关结算三类状态。开始时接收行动编排核心提供的有序参与玩家，不解释这些玩家来自个人、队伍还是宗门同行。

服务在开始时锁定人物、同行道侣和六轮功法感悟结果。**先天灵宝可以在三处介入**：增加每轮感悟判定、提高每轮经验、增加每轮疗养进度（写进结果的疗养倍率）。进度只按经过时间解封完整轮次；个人本人或集体领队可以随时手动出关，未完成轮次作废。人物、道侣、道藏与行为状态由各自核心生成变更计划，按公共结算契约在一笔数据库事务中提交。重启后从会话时间和结算事实恢复阶段，不重新抽取功法感悟。

完整轮次同时交给长期伤势核心治疗人物和同行道侣各自的伤势。高阶伤势未满足每层所需轮数时只累计疗养进度；恢复丹、自然等待和未完成轮次不能替代闭关疗伤。
