# 炼丹核心边界

本核心是炼药规则、丹药和丹师的唯一代码解释入口（丹药自己就是处方）。它按当前位置丹师审药，以一件兽宝为药引，按炉法和药脉从纳戒选择灵植，并在同一数据库事务中扣除材料、加入成丹。

丹师以第三人称主持炼制。炼丹是即时个人行为，不带队、不新增行为状态，也不让同行道侣增加产量。本核心只制造丹药，不执行恢复、战丹、突破或特殊效果；服丹效果由对应玩法解释。

成丹品级只按 `丹则.json` 的最低余量进阶算法计算。其他服务只能使用本包公共契约，不得读取炼药 JSON 或复制选材算法。

缺料清单要把**要求说全**：药引缺的是「某一品级及以上的兽宝」，辅材缺的是「某一品级及以上的某一药脉灵植」，旁脉替代用满时缺的是「本脉灵植（旁脉替代已经用满）」。只写「兽宝」会让手里明明有兽宝的玩家不知道差在哪——难度决定药引与辅材的最低品级，这一层必须在缺料文案里露出来。
