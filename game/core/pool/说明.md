# 资源池核心微服务

`game.core.pool` 是第三个公共核心微服务。它消费 `JsonDataService` 已经建立的实体和资源池索引，不自行读取 JSON。

支持两种正式模式：

- `允许重复`：保留不同池对同一实体的重复引用，每次抽取后放回候选，可重复命中。
- `展开去重`：先按实体编号合并候选，抽取后移出候选，单次结果不重复。

所有候选必须在自身 JSON 定义中提供正整数 `权重`。抽中量与 `1 / 权重` 成正比，因此数值越小越容易抽中、数值越大越难抽中；权重不解释为评分、强度或稀有度标签。随机种子随结果返回，同一数据快照、参数和种子必须得到同一结果。

```python
from game.core.pool import EXPAND_DEDUPLICATED, PoolRequest

result = pool.draw(
    PoolRequest(
        file_ids=("功法-剑诀", "功法-雷法"),
        section="功法",
        count=6,
        mode=EXPAND_DEDUPLICATED,
        seed=123,
    )
)
```

`features` 负责决定为什么抽、抽哪个池和结果归谁；`PoolService` 只负责稳定展开、权重裁决和可复现抽取。结果只返回实体编号和权重，不返回整份 JSON 定义。

资源池可以直接引用实体编号，也可以引用实体源文件或另一份资源池。递归展开、类别检查和循环引用检查由数据服务在启动阶段完成。抽取阶段只读取候选的 `权重` 字段，不复制完整实体正文；同一数据快照中的候选集会在首次使用后缓存，后续抽取只执行随机裁决。

道侣是地点中的城镇 NPC 集合，战场环境和阵法是按编号维护的集合，它们都不使用权重。相关业务通过 `JsonDataService.pool_members()` 展开成员，不能提交给本服务做逆权重抽取。
