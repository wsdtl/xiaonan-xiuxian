# 宗门资源生产核心

宗门资源生产核心解释 `data/宗门/规则` 中的灵脉与灵田生产规则，按周期把宗门设施产出为公共材料。

## 数据与依赖

- 数据集：`宗门规则`；
- 状态类型：无；
- 依赖：`data`、`database`、`sect`、`sect_assets`、`asset`、`pool`、`location`、`sect_progress`。

## 职责

按设施等级与成员贡献计算产量，通过资源池执行实际抽取，并把产出写入宗门公共库。抽取使用 `game/core/pool` 的逆权重算法，随机种子随结果返回，保证可复现。灵田可以在设施状态里记一处选定地形：选了就只从该地形的灵植池抽，没选仍从该物品类别的全池抽；可选地形在启动期逐条核到已登记的灵植池上，对不上直接拒绝启动。

## 边界

本服务不解释资源池候选内容——候选由 JSON 与 `pool` 决定；也不决定成员能领取多少，个人分配由调用方按公开结果处理。生产结果不得直接写入成员纳戒，必须经 `sect_assets` 或 `asset`。地形只收窄物品来源，不改数量、不改随机品级，也不改结算时间与结算序号。
