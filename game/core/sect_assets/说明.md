# 宗门公共资产核心

宗门公共资产核心解释 `data/宗门/规则` 中的公共库与消耗规则，是宗门共有材料与产成品的唯一读写者。它不拥有独立数据库状态，而是通过核心数据库的共享实体接口读写宗门库。

## 数据与依赖

- 数据集：`宗门规则`；
- 状态类型：无（使用共享实体事实，不占用玩家状态类型）；
- 依赖：`data`、`database`、`sect`、`asset`、`character`、`innate_treasure`。

## 职责

维护宗门库中的材料与成品数量，执行存取、转移和消耗，并向设施与生产服务提供可扣减的物料清单。成员个人纳戒与宗门库之间的搬运必须在同一笔事务中完成，避免中途丢失。

## 边界

本服务不解释设施权限、生产配方或贡献等级，也不决定谁能操作宗门库——权限由 `game/core/sect_facilities` 与宗门职衔判定。本服务不得直接改写成员个人资产状态。
