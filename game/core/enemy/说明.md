# 敌人核心

本目录拥有世界敌人 JSON 的解释权，负责按地点敌人池生成完整、可复现的战斗实例与掉落快照。调用方只提交地点池、数量和种子，不读取敌人内部字段。普通敌人、讨伐首领、讨伐辅助和讨伐属从使用独立内容类别；`generate_groups` 为每个编组独立决定人数并独立抽取成员、等级、属性和奖励。

**敌人也分种族层**：种族登记表来自 `角色/规则/种族`，按讨伐档次与实例编号确定性取族（同一次生成永远同一族）。种族给出天生锁定技与卡池来源——生成时决定构筑从哪个卡池抽。（`成长修正`已废除：种族不再提供成长倍率，等级成长不乘任何倍率。）

敌方修士与灵兽共同生成等级、属性、构筑和交锋所得；敌方修士额外生成性别、本命武器和器律，灵兽以实体肉身成长替代武器。掉落在敌人实例生成时固定，每名敌人战败后最多结算一次。
