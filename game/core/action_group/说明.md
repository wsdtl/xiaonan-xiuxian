# 行动组核心

行动组核心把「队伍」与「宗门同行」两种成员来源统一成一次行动所需的顺序参与者列表，不保存自己的状态，也不写数据库。

## 职责

- 从队伍核心和宗门核心取出当前关系，回答「谁和谁一起行动」「谁是领队」；
- 只依赖 `team` 与 `sect` 两个核心服务，不读取任何 JSON 数据集；
- 托管、行路、探险、讨伐、闭关、采药、采矿通过它判断发起资格。

## 边界

本服务不创建队伍、不邀请成员、不改玩家状态，也不决定玩法奖励。队伍与宗门的成员事实仍分别归 `game/core/team` 与 `game/core/sect`；行动组只是它们的只读投影。参与者顺序变化由来源服务决定，本服务不重排。
