# 阵法核心边界

本核心是 54 座阵法、五个品级、固定消耗与圣品无上限、阵师开放范围和一次性阵法状态的唯一代码解释入口。

炼阵只读取兽宝、灵矿、灵植的类别、品级和数量，不读取材料名称背后的药性或战斗能力。

**先天灵宝可以在「阵法成形」这一步介入**：能力为「提高总势」时给整体总势加 `比例` 倍率，能力为「提高材料阵势」时只给 `材料` 指定的那一类材料加 `比例` 倍率（阵势倍率会随阵法一起进快照）。这次激活会写进结果，由回复展示。天地玄黄按固定消耗炼制并在阵藏中合并；圣品保存三类材料的总投入，每个实例独立存在，超出最低值的部分才进入材料倍率。材料扣除和阵藏增加使用同一事务。

布阵把一份阵藏实例转换为唯一的待战阵法。下一场正式战斗建立时，调用方取得不可变战斗快照和清除计划；战斗核心只执行快照，不读取阵法 JSON，也不重新计算材料倍率。
