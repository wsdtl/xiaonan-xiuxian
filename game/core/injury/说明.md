# 长期伤势核心

长期伤势核心解释 `data/角色/规则/伤势` 与 `data/角色/内容/伤势.json`，独占数据库状态类型 `injury`。人物使用状态键 `player`，道侣使用 `companion:<道侣编号>`，两者互不覆盖，不新增数据库表。

外来伤势只接纳敌方施加、战斗结束后仍存续且已在 JSON 登记的负面状态。境界自生伤势只根据该角色本场真实资源结局和战斗事件产生，每场最多新增 JSON 规定的数量。已有长期伤势不会因单场战斗状态耗尽而消失，而是在下一场重新装配。

服务负责把伤势翻译成战斗核心的战前状态，保留层数、行动限制和监听节点。探险、宗门战负责把演化后的伤势快照收进各自结算事务；闭关按完整轮次请求治疗计划。恢复丹、等待和采集不得调用治疗。
