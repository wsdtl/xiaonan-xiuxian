# 消息流水日志微服务（tiandao_houtai）

**管什么**：非资产库（`database/runtime_log.db`）里 `log_message_flows` 这张表——维护者观测用的消息流水，
按 `flow_id` 取、按 `created_at`/`expires_at` 过期清理。

**为什么叫这个名字**：二级命令组件「后台/天道后台」所用的玩法微服务，按该组件拼音命名（`微服务边界规范.md` 的命名约束）。

非资产库是**核心的**，库里三个日志各成一个微服务：事务流水、本服务、战报。

## 边界

- 维护者入口经本服务读流水：日志是观测数据，**不是游戏规则、不是玩家资产、也不是战斗事实**；
- 非资产库路径由 `runtime_log_database_path` 解析（框架自定义项，不进 `game/config.py` 的配置面）。

## 来历

2026-10-14 从 `game/cmd/后台/天道后台/storage.py` 搬到玩法层：非资产库的存取归核心，
而命令组件用的那个微服务按它自己的拼音命名。
