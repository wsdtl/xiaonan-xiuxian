# 道侣核心微服务

本服务解释正式道侣 JSON 的身份、喜爱灵植、话语、回礼、实例范围和地点归属，同时拥有玩家个人的关系、同行位与轻实例状态。其他玩法只通过稳定契约查询或申请状态变更，不解释道侣 JSON 和数据库正文。

**道侣也有种族层**：可选族池来自 `角色规则.道侣.可选种族`，种族登记表由组合根在角色核心就绪后回填（回填时校验池里的族名都已登记，否则启动即错）。**同一名道侣永远同一族**——按编号确定性取族，不随会话变化；种族提供天生锁定技（交给参战者固有规则）与卡池来源。

关系使用 `companion_relation/<道侣编号>`，同行位使用 `companion_active/main`，轻实例使用 `companion_instance/<道侣编号>`。静态姓名、性别、所在地、话语和池引用永远来自 JSON，不复制到玩家状态。首次邀约在一笔事务中同时固定资质、属性倍率、首次邀约时间和同行位；暂别只删除同行位。

本服务不扣除背包、不发送回复，也不实现道侣培养、队伍或战斗编排。赠礼玩法从资产核心取得库存变更计划，再把库存与关系操作合并成同一数据库事务。

铜雀台重置通过正式道侣定义、已固定资质和属性倍率重建一级初始属性，清除等级成长、突破永久属性和突破记录。功法、真意、气机与本命武器属于独立培养事实，不因人物等级重置而删除。
