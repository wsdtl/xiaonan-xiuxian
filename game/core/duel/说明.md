# 切磋核心

切磋核心解释 `data/切磋/规则/玩法规则`，独占 `duel_challenge` 与 `duel_result` 两类数据库状态，负责同处玩家之间的挑战建立、应战与结算。

## 数据与状态

- 数据集：`玩法规则`；
- 状态类型：`duel_challenge`（待处理挑战）、`duel_result`（不可变战果）；
- 依赖：`data`、`database`、`location`、`character`、`companion`、`player_state`、`action_group`、`combat`。

## 职责

校验双方同处一地且都处于可战斗状态，把双方与各自同行道侣的构筑交给战斗核心执行，并把结果写入战果状态。它使用 `action_group` 判断同行成员，不自行拼装参战名单；实际伤害、行动条与状态结算全部由 `game/core/combat` 完成。

## 边界

本服务不发放战利品、不掉落物品、不修改纳戒，也不处理邀请以外的社交关系。战果状态只由本服务写入；其他玩法不得直接改动 `duel_*` 状态。
