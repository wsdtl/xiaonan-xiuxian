# 切磋核心

切磋核心解释 `data/玩法/切磋/规则/切磋.json`，独占 `duel_challenge` 一类数据库状态，负责同处玩家之间的挑战建立、应战与结算；战报是**非资产数据**，结算后登记进非资产库（按编号分享、到期即清理），不写进玩家状态。

## 数据与状态

- 数据集：`玩法规则`；
- 状态类型：`duel_challenge`（待处理挑战）；
- 非资产记录：战报写入非资产库的 `log_battle_reports`（编号、类型、参战者、完成时间、战报本体、到期时刻），由运行期基础设施提供读写与清理；
- 依赖：`data`、`database`、`location`、`character`、`companion`、`player_state`、`action_group`、`combat`。

## 职责

校验双方同处一地且都处于可战斗状态，把双方与各自同行道侣的构筑交给战斗核心执行，并把战报登记进非资产库。它使用 `action_group` 判断同行成员，不自行拼装参战名单；实际伤害、行动条与状态结算全部由 `game/core/combat` 完成。

## 边界

本服务不发放战利品、不掉落物品、不修改纳戒，也不处理邀请以外的社交关系。战报只由本服务登记，且只登记进非资产库；分享地址只需要战报编号，与谁发起、存在谁名下无关。待处理挑战状态只由本服务写入；其他玩法不得直接改动 `duel_*` 状态。
