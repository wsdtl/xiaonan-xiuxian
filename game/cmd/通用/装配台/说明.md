# 装配台二级组件

## 入口

| 命令 | 行为 |
| --- | --- |
| 装配台 | 打开公开 `/assembly`，无须登录，未创建人物也可研究 |
| 我的装配 | 导出自己当前整套装配与装配码 |
| 导入装配 装配码 | 按执行者资产与人物规则整套校验、消耗、提交 |
| 公开池 | 唯一公开开关，默认关闭，再次发送即关闭 |

没有单槽聊天命令，也没有“私密池”第二开关。既有的单项人物培养命令继续由原组件处理。

## 页面与接口

- `GET /assembly`：HTML，CSP 只允许本站资源。
- `GET /assembly/data?scope=all`：完整构筑目录；与所有已公开用户同级。
- `GET /assembly/data?scope=user:身份`：仅已公开用户的装配候选与当前构筑。
- `POST /assembly/scheme`：提交 `{"build": 四类槽位}` 或 `{"code": 装配码}`，
  只解析/生成公开方案，绝不写玩家存档；请求体上限 32 KiB。
- 页面和 JSON 都是 `no-store`；静态文件沿用项目 ETag。
- 任意人可以打开链接与装配码；不引入登录、签名或目标用户绑定。
- 关闭公开后新读取立即拒绝；浏览器已看过的内容与已分享的码不可能追溯收回。

`__init__.py` 只注册命令和接转服务；`site.py` 适配 HTTP；
`reply.py` 只构造 DocumentMessage，不获取服务、不判断资产事实。

## 网页操作

默认全池；选自己或别人都通过同一平级清单列表，用户先开启公开才出现在列表。
切换范围只筛候选，不清除已编排方案；“以此人当前装配填入方案”是显式覆盖操作。
先选槽位，再点候选填入；可逐槽清除、清空全套、载入码、生成码和复制聊天导入命令。
页面不自动保存，关闭前复制装配码。全部空槽的码表示卸下整套，不是跳过修改。

`GET /assembly/content?section=类别&content_id=编号` 按需读取该内容的正式能力正文，复用战斗核心渲染器；公开目录内容不绑定用户清单。
