# 这是产物目录，不入库

工具的中间产物统一落在 `_输出/`。`.gitignore` 只放行这一份说明：

```
/_输出/*
!/_输出/说明.md
```

所以**新克隆里只有这份说明**，没有任何产物——需要时由工具自己建目录（各工具的 `--报告` / `--输出` 参数默认都指向这里，
例如 `tools/报告与生成/盘点种族.py --输出 _输出/种族基准/改前.md`）。

## 留在目录里的，只该是「可复用的仪器」

- `比回执.py` —— 拿当前状态跑一遍全部注册命令，与基线**逐字节**比对；
- `录回执基线.py` —— 重录基线（改动回执前先留一份，改完再比）；
- `回执基线.json` —— 基线本体。

一次性的验证脚本**用完即删**，别攒着：它们既不入库，留着只会盖住下一个人要找的东西。
